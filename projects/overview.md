# 项目协作概览

项目是 Zenith 中的协作和用量归集范围。它把成员、开发机标签、存储、卡时、配额和通知组织在一起，但不会改变云资源本身的所有权。

## 使用信息

| 项目     | 说明                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 适用角色 | 项目成员可查看项目；项目的负责人和管理员管理项目内容；运维可添加或移出普通成员、修改名称和描述；平台管理员可新建、删除和管理全部项目 |
| 界面路径 | 侧栏 **项目**（所有视图都使用同一个项目列表），点击任意一行进入项目详情                                                       |
| 前置条件 | 你已被显式加入项目，或具备运维 / 平台管理员权限；项目处于“进行中”状态时才能用于新的资源请求                                  |

## 先理解项目标签与开发机所有权

::: warning 项目标签不会转移开发机所有权
把开发机归入项目，只会让项目用量、卡时和配额视图纳入该开发机。开发机仍然属于原来的个人所有者。移出成员、更换负责人、归档或删除项目，都不会把开发机转给其他人，也不会自动删除开发机。
:::

- 项目的负责人或管理员可以管理成员、项目设置、配额和 Webhook。
- 组织归属不会带来项目权限；负责人或项目管理员必须显式添加每位成员并指定项目角色。
- 项目管理权不会授予进入他人终端、注入密钥、迁移其文件、删除、重建或变配其开发机的权限。
- 成员离开项目后，其个人开发机仍归该成员所有，只是不再作为该项目的聚合资源。

## 查看项目列表

1. 在侧栏打开 **项目**。普通用户看到自己参与的项目；运维和平台管理员看到全部项目。
2. 用搜索框按名称、项目标识、描述、负责人或组织查找；搜索覆盖整个列表，不限于当前页。
3. 状态默认只显示“进行中”，可切换为“已归档”或“全部状态”；运维和平台管理员还可以按组织筛选，其他用户可以按“我的角色”筛选。
4. 搜索词和筛选会写入地址栏，从项目详情点页面标题中的 **项目** 返回时会恢复。
5. 列表为空时，需要由项目的负责人或管理员把你加入项目；仅加入项目关联的组织不会获得项目权限。

项目角色含义如下：

| 项目角色   | 主要能力                           |
| ---------- | ---------------------------------- |
| 负责人     | 管理项目设置、成员、配额和 Webhook |
| 管理员     | 与负责人类似地管理项目日常配置     |
| 成员       | 使用项目并查看允许的项目数据       |
| 只读       | 查看项目信息，不修改配置           |

## 新建项目

平台管理员和运维可以新建项目。

1. 在 **项目** 页面点击“新建项目”。
2. 填写项目名称和可选描述；平台管理员还需要填写项目标识（2–48 位小写字母、数字、下划线或连字符），可选择项目类别和所属组织。
3. 选择负责人；留空时默认为你自己。
4. 点击“新建”。成功后会进入项目详情。

项目额度（卡时）不在这里填写，请平台管理员在 **额度策略 › 项目额度** 中配置。编辑时更换负责人或移出、更换所属组织，保存前会再次确认；原负责人保留为项目管理员。若项目已新建但所属组织没有保存成功，抽屉会保持打开并切换为“编辑项目”，再次保存只会补写组织，不会重复新建。

## 项目详情

页面标题显示为 **项目 › 项目名称**：点 **项目** 回到进入详情前的页面（通常是保留了搜索和筛选的项目列表；直接打开详情地址时进入项目列表），按住 Ctrl / ⌘ 点击可在新标签页打开项目列表。

标题下方是项目名称、状态、项目标识（可复制）和你在项目中的角色，下面是一行项目描述（过长时悬停查看全文），再下一行是负责人、所属组织、项目类别和资源区；右侧有 **编辑**、**更多**（归档 / 恢复、删除，仅平台管理员）和 **刷新**（刷新当前标签页）。详情分为 5 个标签页，地址栏中的 `?tab=` 会同步当前标签：

| 标签 | 内容                                                                                       | 可见范围                         |
| ---- | ------------------------------------------------------------------------------------------ | -------------------------------- |
| 概览 | 项目池待分配、已分配未用、成员数、运行中开发机；项目开发机列表（服务端分页与搜索，可点进详情） | 全部                             |
| 成员 | 成员列表、角色筛选、学号目录与 public 目录开关、添加和移出成员                              | 全部（只有管理者可修改）         |
| 卡时 | 项目池、成员卡时、分配与上交、记录和用量趋势                                               | 成员与管理者                     |
| 存储 | 容量、文件、成员权限、我的路径、已绑定存储                                                 | 成员与管理者（后两项部分仅管理者） |
| 设置 | 基本信息、配额、队列保障、训练整机预约（实验性）、Webhook、危险操作                                  | 管理者；运维只见基本信息         |

运维打开项目详情时只显示“概览、成员、设置”三个标签。旧链接中的 `?tab=allocation`、`usage`、`quotas`、`webhooks`、`object-storage` 会自动转到对应的新标签。

## 管理项目基本信息

项目的负责人、管理员或平台管理员点击“编辑”：

- **项目名称**：必填。
- **项目标识**：一经设置不能修改；尚未设置时可以留空。
- **负责人**：从有效账号中选择新的负责人。保存后，原负责人保留为项目管理员。
- **描述**：记录目标、数据范围或负责人信息，避免写入密码和凭据。

若提示“项目负责人已变更”，请刷新项目后再编辑，以免覆盖他人刚保存的修改。负责人候选暂时无法加载时，仍可保留当前负责人并修改其他信息。

## 添加和调整成员

1. 进入“成员”标签。顶部的角色标签显示各角色人数，点击可筛选。
2. 按姓名、登录名、邮箱或角色搜索；搜索覆盖整个项目，不限于当前页。
3. 点击“添加成员”，选择一个或多个用户和项目角色，再点击“添加”。运维视图添加的成员固定为“成员”角色。
4. 在成员行的“角色”列选择新角色，确认后立即生效；改为只读会收回项目存储的写权限。
5. 点击“移出”并确认。移出后该成员将失去该项目的访问权；如仍有开发机或训练任务使用项目存储，会被拦截，并列出阻塞的开发机或训练任务。

保存时会先读取最新成员名单，只叠加你这一次的修改，不会覆盖他人刚添加的成员。一次修改进行中时，其他成员操作会暂时禁用。

“学号目录”和“public”两列开关立即生效：开启无需确认；关闭会先确认，关闭只取消对应目录的自动授权，文件不会移动。缺少学号的成员不能开启学号目录，可点击“同步学号”。

## 项目存储

“存储”标签顶部显示项目额度和各存储单元的已用 / 配额（采样值）。下方分为：

- **文件**：浏览本项目向你授权的文件存储和存储桶。
- **成员权限**（管理者）：选择存储和成员，添加“指定子目录”或“整个绑定范围”的授权，选择只读或读写后点击“保存目录授权”。修改在保存前只是草稿，页面会标出“有未保存的修改”；切换存储或成员前会询问是否放弃修改。保存会覆盖此成员在该存储上的目录授权，清空即全部撤销；撤销或降低权限前会再次确认。存储桶还可以在“全体成员可访问”和“按成员授权”之间切换。
- **我的路径**：为新建的开发机和训练任务添加兼容挂载路径；已有的不受影响。
- **已绑定存储**（管理者）：项目绑定的文件存储和存储桶。平台管理员可以“绑定存储”、解绑、为文件存储“授权”非成员挂载、“编辑”存储桶绑定的范围和读写权限（已启用成员目录权限的桶需解绑后重新绑定；改为只读或更换范围前会再次确认），并在“存储配置”中切换存储模式、登记独立文件系统、设置项目存储额度和启停项目存储。

权限会和其他来源叠加；收回权限后，已签发的链接和临时凭据仍有效至到期。已有开发机需要重新挂载后才按新权限生效，降低权限前请先停止使用该目录的开发机。

## 配额

在“设置 › 配额”中，新建或启动开发机时会检查“同时运行”和“总提交”上限，用户配额与项目配额都需满足；留空表示不限。“项目总量”限制全项目合计，成员行只限制该成员在本项目内的用量。编辑时适用范围锁定；已有配额的范围在新建时不可选。详见[项目配额、卡时与费用](/projects/quotas-billing)。

## Webhook

项目事件会以 HTTP POST 推送到你配置的地址。

1. 进入“设置 › Webhook”，点击“添加 Webhook”。
2. 填写名称、外部 HTTPS 地址和可选签名密钥。
3. 选择订阅事件；不勾选表示订阅全部事件。
4. 保存后点击“测试”检查接收端。停用 Webhook 前会再次确认，之后的事件不再推送，可随时重新启用。

配置签名密钥后，请求会带 `X-Zenith-Signature: sha256=…`（HMAC-SHA256 正文签名）；`X-Zenith-Event-Id` 可用于接收端去重。测试成功仅表示当次接收正常；项目通知属于尽力发送，接收端应做好幂等处理并自行监控。

## 归档、恢复或删除项目

- **归档**：项目结束但仍需保留成员和历史时使用，由平台管理员操作（项目负责人和管理员不能归档或恢复）。归档后整页只读，成员只能查看，不能新建资源或修改配置；可随时“恢复”。
- **删除**：仅平台管理员可执行。成员、配额、Webhook 和项目额度会被删除，项目存储绑定与成员目录授权会被撤销（文件保留），开发机保留；删除后无法恢复，并回到项目列表。

::: danger 删除项目不会删除云资源
删除项目后，开发机仍然存在并继续归原用户所有，也可能继续运行和消耗卡时。删除前应逐项检查开发机、训练任务和存储，并按实际需要另行停止或释放。
:::

## 常见问题

### 为什么我是项目管理员，却不能操作别人的开发机？

项目角色只管理项目范围，不会自动提升平台操作权限。请确认你是否具备执行该操作所需的平台角色。

### 删除项目后开发机去哪了？

开发机仍属于原所有者，只是不再带有该项目标签。请从所有者的“我的开发机”或有权限的“开发机管理”页面查找。

### 为什么不能把开发机改到另一个项目？

跨项目改挂仅平台管理员可做，以避免卡时和配额归集被随意改变。请联系平台管理员处理。
