# 厂商与能力差异

Zenith 为火山引擎、天翼云、无问芯穹（Lanqi / Infini-AI）和阿里云提供统一入口，但不会把不同厂商强行变成完全相同的产品。

::: warning 页面提示是当前环境的准确信息
本页用于解释常见差异，不是能力承诺。实际能力会受到账号权限、区域、库存、产品模式、网络和当前部署版本影响。请始终以控制台当前页面的能力标签、按钮状态和错误提示为准。
:::

## 为什么同一页面在不同厂商下不同

厂商差异通常来自以下方面：

- 使用的是标准云主机、开发机还是训练平台等不同产品。
- 账号只获得部分服务或只读权限。
- 地域和可用区没有对应规格、镜像或存储。
- 厂商没有提供某类公开接口，或当前部署没有启用该能力。
- 资源处于不允许变更的状态。
- 当前连接不可用，页面无法确认能力和数据。

因此，一个资源区可以从厂商目录里挑选镜像，另一个只能逐条登记完整地址，是正常的能力差异，不一定是故障。

## 四家厂商各自锚定一条产品线

Zenith 不会把同一厂商的所有云产品都接进来。当前控制台只围绕下表这条产品线工作；页面上的队列、存储和计费徽标都按这条线解释。

| 厂商 | 当前产品线 | 包里通常有什么 | 对你意味着什么 |
| --- | --- | --- | --- |
| 火山引擎 | 机器学习平台 MLP（预付队列 + vePFS） | 预付队列里的开发机/任务，以及包内高性能存储 | 日常创建走包内队列，不是去买一台裸云主机。对象存储（TOS）的现金口径若未确认，页面会标“计费未知”，不要把它当成免费或按量。系统云盘仅总管理员可扩容（只能增大），用户和项目管理员不能操作 |
| 天翼云 | 科研助手 BC 专属资源池 | 已预付专属池（实例显示 ¥0/时）和框架镜像自带的非持久系统盘 | 选择多卡是同一台开发机的规格放大，不是多台机器。平台不提供池外按量购买入口。停止或重启前把文件写到已挂载研究存储，系统盘不支持自助扩容 |
| 无问芯穹（Lanqi / Infini-AI） | 项目池包月套餐 | 包内 RESERVED 资源池，以及套餐内的高性能/容量型文件系统 | 包内开发机和包内开子卷不消耗账号余额。只有 SPOT/ELASTIC 等按量档位才会烧现金，创建向导会单独标注。预留机把持久数据放在 POSIX 挂载上，不提供根盘扩容 |
| 阿里云 | 产品线尚未锁定 | 以当前页面实际开放的只读或生命周期能力为准 | 不要假定可以从 Zenith 下付费单或买到稳定套餐；计费徽标通常为“计费未知” |

::: warning 余额低不等于包内资源不可用
火山、天翼、无问的包内计算和包内存储不看账号现金余额。余额只影响明确标为“按量”的操作。反过来，包内也不是无限：真正卡住创建的通常是队列/资源池容量、个人或项目配额、卡时额度，而不是余额数字。
:::

## 如何阅读“包内 / 按量 / 计费未知”

实例、存储和创建向导会尽量给出三种计费徽标：

| 徽标 | 含义 | 你会看到什么 |
| --- | --- | --- |
| 包内（绿） | 包月或专属池资源，不产生现金消耗 | 不出现“余额不足”一类提示；停止或删除仍可能释放配额和卡时 |
| 按量（黄） | 将产生现金消耗 | 创建向导会写明“将产生现金消耗”；无问的 SPOT/ELASTIC 档属于此类 |
| 计费未知（灰） | 厂商没有给出可信计费形态 | 页面不会猜测成包内或按量。阿里云以及未确认口径的对象存储常见这种状态 |

不要根据其他厂商的经验，把“计费未知”当成免费或按量。以当前行上的徽标和创建页提示为准。

## 四家厂商的常见能力侧重点

下表是帮助理解页面差异的参考，不应替代实时能力提示。

| 厂商 | 当前环境中可能重点出现的能力 | 常见注意事项 |
| --- | --- | --- |
| 火山引擎 | MLP 开发机、预付队列、镜像仓库、训练任务、vePFS 快速存储和 TOS 对象存储 | 当前部署走 MLP，不是 ECS 裸买。队列、训练和资源组只在相应模式出现 |
| 天翼云 | BC 开发机完整生命周期、公共/社区/自定义镜像、专属队列、JupyterLab 应用链接、科研存储清单和 ZOS 对象存储 | 专属池不支持本地盘；科研存储需创建后到天翼控制台挂载；子账号不能登记 BC 公钥时会降级为 JupyterLab |
| 无问芯穹（Lanqi / Infini-AI） | 纳管项目池中的开发机生命周期、镜像、监控、Web 应用/TensorBoard 链接、包内 POSIX 卷和稳定 SSH 中转端口 | 只有明确授权给所选资源池的卷才可挂载；Code Server/JupyterLab 需在开发机内启动并配置监听端口；应用链接需要无问登录会话 |
| 阿里云 | 页面当前开放的实例查看或有限生命周期、镜像和部分监控 | 产品线未锁定，不要从本平台发起付费购买；队列、训练、快速存储或对象浏览可能不在统一入口中 |

同一厂商在其他 Zenith 部署中可能与表中不同。

## 如何阅读能力提示

| 页面状态 | 含义 | 建议 |
| --- | --- | --- |
| 可用按钮 | 当前页面判断角色和厂商能力满足基本条件 | 提交前仍检查资源状态、配额、价格和参数 |
| 按钮禁用并显示原因 | 缺少平台权限或当前厂商不支持 | 阅读悬浮提示，不要重复刷新或绕过 |
| 不支持 | 当前产品模式没有提供该能力 | 改用支持的厂商/资源，或联系管理员确认方案 |
| 连接不可用 | 暂时无法获取数据或执行操作 | 稍后刷新；持续失败时联系管理员 |
| 权限不足 | 平台角色、所有权、项目关系或厂商权限不满足 | 对照[角色、身份与权限](/reference/permissions)逐层检查 |
| 获取失败 | 本次请求失败，不能据此判断资源为空 | 记录完整错误、时间、厂商和资源 ID 后重试 |

## 计算资源

实例创建页面会根据厂商能力展示不同字段。可能出现的选项包括地域、可用区、规格、队列、资源池、镜像、磁盘、网络、SSH 和挂载。

提交前请注意：

- 不要把一个厂商的规格 ID、队列 ID 或镜像地址复制到另一个厂商。
- 页面没有提供的网络、端口或标签字段，不代表系统会采用你预期的默认值。
- 询价结果、容量和库存都可能变化，只能作为提交前参考。
- 创建成功后，资源出现在列表中可能需要短暂同步时间。

当前环境已用真实 A100/H100 开发机验收天翼云和无问的创建、运行、重启、停止、启动与
删除/释放链路。页面仍会按实时池容量、厂商挂载授权和账号权限收敛选项；没有出现的磁盘或
挂载不能通过手填账号全局资源 ID 绕过。

## 镜像

不同资源区直接登记对应平台的镜像地址或原生 ID。管理员在 [镜像](/assets/images) 中导入平台镜像；普通用户可以在火山和百度资源区登记个人或项目镜像。创建时只提供当前账号有权使用的登记，平台镜像还须保持启用。云平台目录中的其他标签不会自动加入清单。

火山 MLP 按仓库和标签选择；其他资源区沿用对应产品目录。登记不转换格式、不复制镜像，也不配置云端拉取权限。开发机和训练任务仍须符合目标平台的运行要求。

百度百舸和火山 MLP 均可从自己的运行中开发机详情页 **保存为镜像**，完成后自动加入对应资源区的个人镜像。平台使用已有的云账号和仓库授权，用户不需要填写仓库密码。保存期间请勿停止、重启或修改环境；挂载存储中的数据不包含在镜像内。

## 训练与推理

训练任务、队列、任务实例、资源预约、日志和推理服务通常与厂商的训练平台能力有关。常见情况包括：

- 可以创建任务，但日志需要跳转到厂商控制台查看。
- 可以查看任务列表，但不能修改优先级或资源预约。
- 厂商产品存在推理能力，但当前 Zenith 页面不开放创建。
- 学生制度账号可不选项目创建训练任务，无有效正式项目资格时仅限低优；其他非运维管理员仍需选择有写入权限的有效项目。

页面给出的“打开厂商控制台”链接是补充查看入口，不代表 Zenith 会同步厂商控制台中的所有字段。

## 存储与文件

- 对象存储浏览只在部分厂商可用。
- 快速存储可能以不同类型的文件系统呈现。
- 天翼科研存储当前只在 Zenith 展示清单；请先创建开发机，再到天翼控制台执行存储变更。
- 无问创建向导只展示所选资源池的可挂载卷；显示“当前资源池没有授权卷”时可以无挂载创建。
- 存储容量字段缺失时，不能把它解释为零容量。
- 文件分享只对页面明确提供分享入口的对象开放。
- 跨云迁移与对象存储浏览是两项独立能力；能浏览对象不等于可以迁移实例路径，反之亦然。

## 监控与费用

监控指标、历史曲线、余额、账单和询价的支持范围各不相同。页面没有 GPU 指标时，不代表 GPU 没有工作；可能只是当前厂商或账号未提供该指标。

账户余额只在进入页面或手动刷新时查询，且可能限频。请把三种状态分开看：

- **不支持：** 当前厂商没有余额接口（天翼云常见）。
- **获取失败：** 这次没查到，不能当成余额为零。
- **显示金额：** 只说明账号现金水位；火山、天翼、无问的包内资源不消耗它。无问余额只影响按量档位。

Zenith 的费用汇总主要依据采样用量和管理员维护的静态价表估算，不是云厂商账单或发票。即使某个厂商显示余额或费用数据，也应以厂商账单和组织结算规则为最终依据。

## 提交问题时需要的信息

报告厂商相关问题时，请提供：

- 云厂商和页面名称。
- 地域、可用区、资源类型和资源 ID。
- 操作时间和操作名称。
- 页面显示的能力状态和完整错误提示。
- 是否只有一个厂商失败，其他厂商是否正常。

不要提供密码、API Token、云账号密钥、签名下载链接或未脱敏数据。
