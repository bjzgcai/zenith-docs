# 角色、身份与权限

Zenith 的权限不是由一个标签决定。控制台会同时考虑平台角色、产品身份、项目角色、资源所有权和厂商能力。

```text
能否操作
├── 平台角色：viewer / operator / operations / admin
├── 产品身份：普通用户 / 项目管理员 / 运维 / 平台管理员
├── 项目角色：负责人 / 管理员 / 成员 / 只读
├── 资源所有权：是否为实例、模型、文件等资源的所有者
└── 厂商能力：当前连接、区域和产品模式是否支持
```

## 平台角色

平台角色是全局权限基础，采用从低到高的层级：`viewer < operator < operations < admin`。

| 平台角色 | 主要能力 | 仍然受到的限制 |
| --- | --- | --- |
| 访客（`viewer`） | 查看当前数据域允许读取的内容，管理自己的 SSH 公钥、API Token、模型等个人资产 | 不能发起厂商侧计算资源变更；实例和部分聚合按本人或参与项目限制，公共资产和全局只读页面可能采用不同可见范围 |
| 普通用户（`operator`） | 包含访客能力，并可创建、启动、停止等资源操作 | 仍需满足资源所有权、项目关系、配额和厂商能力；不是系统管理员 |
| 运维（`operations`） | 在普通用户能力之上增加运维视图，可查看全平台资源、开关开发机、创建与修改支持的资源、维护项目并添加成员 | 运维视图不能删除资源、访问文件内容或打开终端；不能修改平台管理员权限、已有账号密码、平台凭据与发版；API Token 不继承运维权限 |
| 平台管理员（`admin`） | 平台级管理、全局查看和资源操作 | 仍应遵循最小权限、变更审批和数据安全规则 |

`operator` 代表“可以尝试执行资源变更”，不是对所有资源的无条件访问。普通用户仍然要通过所有权和项目规则；运维只在明确开放的运维接口中获得跨用户权限。

Zenith 当前是一个全局资源域，不提供独立租户隔离。不同页面会按所有权、项目关系、共享范围或平台管理员配置缩小可见内容，但不能把任一页面的范围规则推断为整个平台的统一隔离边界。

## 一个账号只设置一个平台角色

平台管理员在“用户管理”的列表、账号详情或创建账号窗口中，单选平台管理员、运维、普通用户或访客（只读）。
角色调整后需要重新登录；已有组织、项目、存储和卡时记录会保留。

- **平台管理员**：管理平台，可通过视图切换器预览其他导航；预览不会改变服务端角色。
- **运维**：保留普通用户能力，并增加运维视图。在运维视图中，存储仅显示管理信息，不能浏览文件内容、签发临时凭据、调整挂载或配额，也不能打开用户终端；切回用户视图后可按普通用户权限使用本人的资源。
- **普通用户**：使用本人有权访问的开发机、终端、文件和项目资源，仍受所有权、项目及额度规则约束。
- **访客（只读）**：只读访问允许查看的内容，不能发起计算资源变更。

项目的负责人或管理员由项目成员关系决定，无需再添加第二个平台角色。
普通用户、访客或运维在实际管理项目时，可切换用户和项目管理员视图；视图切换不会提升平台角色。
“学生／研究员”由组织归属确定，设置运维角色不会自动加入项目。

升级到单选角色版本时，原有多角色账号保留数据库中已保存的第一个角色，其他角色移除，
相关账号需要重新登录。例如“普通用户、访客”保留普通用户。旧版本保存时曾按角色优先级排序，
因此这里的第一个角色指已保存的顺序，不是最初点击选项的先后顺序。

## 产品身份

产品身份主要决定控制台导航和页面呈现，不是新的平台角色。

| 产品身份 | 如何形成 | 典型页面 |
| --- | --- | --- |
| 普通用户 | 普通用户、访客和运维均可使用用户视图；未管理项目的普通用户或访客默认进入此视图 | “工作台”下的我的总览、我的开发机、我的训练任务、镜像、我的存储、数据集；“协作与支持”下的项目、我的用量、我的工单 |
| 项目管理员 | 平台角色为普通用户、访客或运维，并显式担任至少一个项目的负责人或管理员 | 与普通用户相同的菜单；「开发机」「训练任务」页可切换到 **项目** 范围 |
| 运维 | 平台角色为 `operations` | “运维”下的运维资源概览、开发机管理、训练任务管理、队列管理、存储管理、镜像；“服务台”下的项目、用户管理、工单受理、站点维护 |
| 平台管理员 | 平台角色为 `admin` | “平台运维”“算力”“存储与数据”“账号与组织”“卡时”“服务台”“预览功能”七组；个人页面只通过右上角视图切换预览 |

产品身份与平台角色可以交叉。例如，一个项目管理员仍可能只有 `viewer` 平台角色，此时可以管理项目配置，但不能发起需要普通用户（`operator`）角色的计算资源变更。

平台管理员可以使用右上角视图切换器，预览运维、项目管理员或普通用户看到的导航；预览期间页面顶部有提示和 **退出预览** 按钮。预览不会降低平台管理员账号在服务端的真实角色；个人任务、项目任务和全局任务分别显式请求 `mine`、`projects`、`all` 数据范围。点 **退出预览**（或在视图切换器中选回平台管理员视图）后，会恢复全部平台管理入口。

## 运维账号与 API Token

平台管理员在“用户管理”中把账号角色设为“运维”后，该用户登录即可进入独立运维视图。
运维是附加能力，不会取消用户视图。点击右上角视图切换器 → **用户视图**，即可使用本人的开发机、终端、文件、任务和个人资产。
如果同时是某个项目的负责人或管理员，还可选择 **项目管理员视图**；仅有普通项目成员身份时不会出现此选项。
这些视图按普通用户的所有权、项目关系、存储授权及额度规则执行，不会借用运维权限访问其他用户的文件或终端。
切回 **运维视图** 后恢复运维菜单；切换视图不会修改账号角色、项目成员关系或资源归属。

“项目”支持新建项目、修改名称和描述、把已有账号加入为普通成员；“用户管理”支持
创建普通用户或访客账号、修改这些账号的姓名。运维可维护普通账号的邮箱、存储标识与普通组织／项目成员关系。

已有账号需要从访客改成普通用户时，进入 **用户管理 → 维护用户 → 平台角色**，选择“普通用户”后点 **保存角色**；也可以改回访客。角色变更后，该用户需重新登录。姓名、邮箱和角色分别保存，修改角色不会改变组织、项目或存储标识。平台管理员和运维账号的角色，以及账号密码、启停状态，仍由平台管理员维护。

运维可以跨用户查询开发机和任务、查看 SSH 与运行日志、开关或重启开发机、校对状态。
代别人开机时仍校验开发机所属用户的额度。存储管理仅展示概览、文件存储和对象存储等管理信息；不提供文件内容、临时凭据、挂载、配额或存储登记变更。

运维权限通过登录会话生效。个人 API Token 继续按本人资源和令牌范围授权，
不能调用运维后台、跨用户操作或管理平台配置。平台管理员也可通过视图切换器预览运维导航。

## 项目角色

项目角色只在单个项目内生效：

| 项目角色 | 项目内能力 |
| --- | --- |
| 负责人 | 查看项目详情和用量，管理成员、项目设置、模板、配额和 Webhook |
| 管理员 | 与负责人类似，可管理项目成员和配置 |
| 成员 | 查看项目详情、用量和自己可访问的项目资源 |
| 只读 | 查看项目详情和允许展示的数据 |

项目角色不会改变用户的全局平台角色，也不会转移实例所有权。项目不是独立租户；它是成员、预算、配额、模板、通知和用量的协作与聚合范围。

运维和平台管理员可以创建项目，删除项目仍仅限平台管理员。删除项目会清理项目配置和资源上的项目聚合标签，不会自动删除实例等真实资源。

## 资源所有权

资源所有权用于保护终端、SSH 公钥注入和破坏性操作。带任务记录的传统文件迁移采用更严格的平台管理员边界。

- 通过 Zenith 创建实例后，创建者通常成为实例所有者。
- 项目标签不改变实例所有者。
- 项目的负责人或管理员不会因为项目角色自动获得其他成员实例的终端或密钥注入权限，也不会获得传统文件迁移权限。
- 模型、文件分享和 API Token 也有各自的所有者边界。

平台管理员可以处理全局资源，但应只在明确授权、故障处置或管理流程中使用该能力。

## 常见操作权限

下表描述控制台的主要规则。厂商能力、连接状态和配额仍可能让符合权限的操作不可用。

| 操作 | 一般需要 |
| --- | --- |
| 查看个人总览、个人资产和参与项目 | 已登录的有效账号，并进入与当前产品身份匹配的菜单 |
| 查看所属组织与项目 | 已登录的有效账号；只返回当前账号的组织归属和显式项目关系 |
| 打开开发机详情地址 | 该实例必须落在当前页面的本人、项目或全局数据范围内；详情地址不会扩大可见范围 |
| 查看自己或参与项目的实例 | 访客（只读）及以上，并符合所有权或项目可见范围 |
| 创建实例 | 普通用户及以上；选择项目时还需项目成员关系 |
| 启动、停止、重启自己的实例 | 普通用户及以上，并且是实例所有者 |
| 启动、停止、重启项目内其他成员实例 | 普通用户及以上，同时是该项目的负责人或管理员 |
| 删除、重建、调整规格或修改开发机 | 普通用户及以上，并且是实例所有者；平台管理员除外 |
| 打开浏览器终端、补注入 SSH 公钥 | 普通用户及以上，并且是实例所有者；项目管理身份不能代替所有权 |
| 查看、发起、取消或审批传统文件迁移 | 平台管理员 |
| 使用资源区5 存储桶数据快传生成临时上传/下载命令 | 普通用户及以上；不会授予传统迁移记录或接入节点主机路径访问权 |
| 查看或变更推理服务 | 平台管理员；当前版本没有可用于普通用户授权的持久化资源所有权 |
| 创建训练任务 | 普通用户及以上；学生制度账号可不选项目，无有效正式项目资格时仅限低优；其他非平台管理员需选择有写入权限的有效项目 |
| 修改或停止训练任务 | 普通用户及以上，并且是任务创建者、项目的负责人/管理员或平台管理员 |
| 管理项目成员、模板、配额和 Webhook | 项目的负责人、管理员或平台管理员 |
| 直接拉入或移除组织普通成员 | 平台管理员；无需成员确认。组织负责人目前是说明性关系，不获得成员维护权限 |
| 创建或删除项目 | 平台管理员 |
| 登记个人模型、管理 SSH 公钥和 API Token | 有效登录账号 |
| 登记个人镜像 | 有效登录账号，资源区5 或资源区10 |
| 登记项目镜像 | 活跃项目的负责人、管理员或成员；项目角色为只读的成员不能登记 |
| 保存开发机为镜像 | 具备操作权限的开发机所有者或平台管理员，且资源区已开放并配置保存能力 |
| 导入资源区可用镜像、启用或停用登记 | 平台管理员 |
| 浏览厂商原生镜像库并导入所选项 | 平台管理员 |
| 用户、纳管资源、审计、公告和发版管理 | 平台管理员 |

## 共享不等于转移所有权

- 资源区5 和资源区10 开放个人、项目镜像登记。个人镜像仅本人使用，项目镜像限当前项目成员使用；平台镜像由平台管理员统一导入和启停。
- 模型只有“仅本人”和“平台共享”，不支持项目共享。
- 共享扩大可见范围，但不会授予模型存储或云资源权限。
- 共享通常不可撤回，也不会把资产所有者改成使用者。

新的开发机和任务须使用目标资源区当前有权访问的已登记镜像。提交时会重新核对个人所有权、项目成员身份和平台镜像启用状态。详情见[镜像](/assets/images)和[模型](/assets/models)。

## API Token 的权限

个人 API Token 按本人资源、当前项目关系及所选权限范围授权，不继承跨用户的运维或平台管理员权限。账号被禁用、角色被调整或 Token 被停用后，访问会相应受限。

Token 明文只在创建时显示一次。不要在帮助文档、工单、截图、代码仓库或聊天记录中粘贴真实 Token。

## 为什么我能看到页面，却不能点击按钮

常见原因包括：

1. 产品身份允许进入页面，但平台角色只是访客（只读）。
2. 账号是普通用户，但不是目标资源所有者。
3. 账号管理某个项目，但资源没有标记到该项目，或操作不属于项目管理员的有限生命周期范围。
4. 当前厂商、区域或产品模式不支持该操作。
5. 厂商连接、平台服务或数据库暂时不可用。
6. 个人、项目配额或月度卡时额度不足。

查看禁用按钮旁的说明、页面顶部提示和完整错误信息。仍无法判断时，按照[常见问题排查](/troubleshooting/common)准备信息后提交工单。
