# 工单与钉钉帮助

从页头 **帮助 → 提交工单** 或 **我的工单 → 工单** 右上角的“提交工单”提交需求。支持资源申请、存储申请、故障报修、账号权限、功能缺陷、功能建议和其他帮助。开发机云盘不够用时，请直接在开发机的 **更多 → 扩容云盘** 提交，不必另开工单。

填写标题和详细说明，附上资源区、项目或开发机编号、发生时间和脱敏后的错误信息。不要填写密码、Token、私钥或云账号密钥。提交申请不会立即分配资源或修改权限，由平台管理员处理。

## 在钉钉中提交

使用已绑定 Zenith 的钉钉账号，打开平台通知机器人的**单聊**：

1. 发送 **帮助**。
2. 点击卡片按钮选择资源、存储、故障、账号权限或其他帮助，也可以回复数字。
3. 用文字描述需求和相关资源信息。可连续发送多条消息，机器人会累积到草稿中，合计最多 4000 字。
4. 核对最新卡片的摘要，点击 **确认提交**。也可以点击 **修改** 重写说明，或 **取消** 放弃草稿；回复同名文字也有效。

草稿保留 30 分钟。回复 **帮助** 会显示当前步骤并保留草稿；**新建工单** 重新开始。草稿更新后请使用最新卡片，旧按钮不能提交更新后的内容。当前支持文字提单；图片或文件请先用文字说明内容。群聊不受理个人工单。尚未绑定平台账号时，先用钉钉登录平台；机器人不会按昵称猜测账号。

## 查看和补充

网页 **我的工单 → 工单** 列出你的全部工单（最近 500 条），可按编号或标题搜索、按状态筛选；有新进展的工单标题前有圆点。点击一行打开详情，可看到完整编号（可复制）、接单人和进展，并在“补充说明”中发送补充。工单已解决后不能再补充，如问题仍在，点击“提交跟进工单”。钉钉单聊支持：

| 发送内容 | 功能 |
| --- | --- |
| 我的工单 | 查看最近 5 条工单和完整编号 |
| 查看 完整编号 | 查看自己的工单详情及最近说明 |
| 补充 完整编号 说明内容 | 为尚未结束的工单追加信息 |
| 扩容工单 | 查看最近的云盘扩容申请进度 |
| 帮助 | 查看当前步骤和按钮，保留草稿 |
| 新建工单 | 重新开始申请 |

处理人回复和状态变化会通过已绑定的钉钉账号通知。通知可能延迟或失败，平台工单记录仍然有效；以网页中的工单状态为准。每小时最多提交或补充 10 次，请把同一问题的信息集中在原工单。

**已转交研发** 表示平台管理员已在 GitHub 建了 Issue。进度以本工单为准；补充说明不会自动同步到 GitHub。

## 云盘扩容

扩容申请从 **我的开发机 → 更多 → 扩容云盘** 提交，在 **我的工单 → 云盘扩容** 查看；待审批的申请可以撤回（需确认）。同一台开发机有未完成的申请时不能重复提交。批准后仍需后台执行并核实云端容量，**已批准不等于扩容完成**。详见[扩容云盘](/compute/workbench#扩容云盘)。

## 工单受理

运维和平台管理员在 **服务台 → 工单受理** 处理工单：可按编号、标题或提交人搜索，按状态、分类和“待接单 / 我接的”筛选（“待接单”只列出还没人接、仍待处理的工单）。详情中按状态提供接单、放弃接单、标记已解决、关闭（需确认）、重新打开和转交研发（需确认，仅平台管理员）；处理后列表停在当前页。平台管理员还会看到 **云盘扩容审批** 标签和“钉钉提单”状态，点击状态可查看诊断。项目管理员和普通成员仅查看自己的工单。
