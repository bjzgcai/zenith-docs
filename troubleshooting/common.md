# 常见问题排查

遇到页面空白、按钮不可用、状态不更新或操作失败时，先按本页顺序排查。一次只改变一个条件，避免连续重复提交创建、启动、停止、释放或迁移操作。

## 通用排查顺序

1. **确认页面和资源区。** 检查自己是否进入了正确页面、资源区和项目。
2. **阅读页面顶部提示。** 区分连接不可用、能力不支持、权限不足和获取失败。
3. **确认身份和所有权。** 检查平台角色、产品身份、项目角色以及是否为目标资源所有者。
4. **刷新一次。** 等待当前操作有合理的同步时间后再刷新，不要连续点击。
5. **核对参数和 ID。** 启动、停止、SSH、监控、终端和镜像构建都使用 **厂商实例 ID**（名称下方那串），不要用 Zenith 内部编号。同时检查区域、队列、镜像和路径。
6. **保留完整信息。** 记录时间、资源区、资源名称、资源 ID、操作名称和错误提示。

如果只有一个资源区失败而其他资源区正常，通常应优先检查该资源区的连接、账号权限和能力，而不是把问题判断为整个平台故障。

## 登录和页面访问

### 登录失败

- 确认登录名和密码没有多余空格。
- 本地账号被禁用或密码被重置后，需要联系平台管理员确认。
- 使用组织登录入口时，如果跳转中断，返回登录页重新开始一次，不要重复使用旧回调页面。
- 多次失败后不要在工单中发送密码；只提供登录名、时间和页面提示。

### 页面显示“无权访问”或按钮消失

Zenith 同时检查平台角色、产品身份、项目角色和资源所有权。常见情况包括：

- 项目管理员可以在 **开发机** 页查看项目开发机，但平台角色仍是访客（只读）时不能执行资源变更。
- 普通用户可以操作自己创建的开发机，但不能删除其他成员的开发机。
- 项目的负责人可以在满足平台操作权限（非只读账号）时启动、停止或重启项目内开发机，但不能因此打开他人终端或迁移他人文件。
- 组织管理、资源配额、额度策略等管理页面只对平台管理员开放。

详细规则见[角色、身份与权限](/reference/permissions)。

## 列表为空、连接不可用或加载失败

| 现象                   | 可能原因                               | 处理建议                                                 |
| ---------------------- | -------------------------------------- | -------------------------------------------------------- |
| 页面提示“部分资源区暂时无法连接” | 当前无法连接对应资源区 | 稍后刷新；持续失败时提交工单                             |
| 页面显示“不支持”       | 当前资源区或产品模式没有该能力         | 查看[厂商与能力差异](/reference/vendors)，改用支持的入口 |
| 页面显示“权限不足”     | 平台或云端权限不满足                   | 核对角色、所有权、项目关系后提交工单                     |
| 页面显示“获取失败”     | 网络、云端服务或参数异常               | 保存完整错误与时间，刷新一次后再报告                     |
| 列表为空且没有错误     | 当前筛选条件无数据，或资源不在可见范围 | 清空筛选，确认资源区、项目和队列                         |

“没有返回容量”“没有返回监控指标”和“容量为零”“指标为零”不是同一件事。缺失值应按未知处理。

## 状态长时间不变化

创建、启动、停止、释放和训练任务通常需要云端异步处理，列表同步也可能有短暂延迟。

1. 查看页面是否已经提示“命令已下发”或显示任务结果。
2. 等待一段合理时间后刷新一次。
3. 查看列表和详情中的“数据已过期”标签，以及资源区连接状态。
4. 如果页面提供厂商控制台入口，可用它核对厂商侧状态。
5. 状态持续不一致时，不要再次提交相同的破坏性操作；记录两个页面的状态和时间，通过工单提交。

“数据已过期”表示 Zenith 最近没有再次确认该资源，不代表资源已经自动删除。

## 新建开发机失败

按以下顺序检查：

- 当前账号是否为普通用户及以上平台角色（访客只读不能新建）。
- 选择项目时，自己是否为有效项目成员。
- 个人和项目的配额、月度卡时是否足够。
- 资源区、可用区、队列和规格是否相互匹配。
- 队列是否仍有容量，规格是否有库存。
- 镜像地址和架构是否正确，目标环境是否有拉取权限。
- 网络、磁盘和挂载选项是否为页面当前支持的字段。

页面显示询价或容量不代表最终创建一定成功，云端会在提交时再次校验。

### 资源区5的个人授权目录挂载时报 AccessDenied

即使平台管理员已在 Zenith 保存授权，云端调用身份及目标计算队列仍需对同一子目录具备权限。
按[子目录授权排查](/data/fileset-access#access-denied)核对路径和云端配置；不要改为整个存储授权来绕过错误。

## SSH 或浏览器终端无法连接

1. 确认开发机处于运行中，而不是启动中、停止中或标记为“数据已过期”。
2. 确认你是开发机所有者，或使用的是平台管理员账号。
3. 确认详情已显示厂商实例 ID，并且页面提供了 SSH 地址或终端入口；资源区6 优先使用“平台中转 · 固定端口”。
4. 确认开发机所在资源属于当前允许连接的范围。
5. 检查个人 SSH 公钥是否为 OpenSSH 单行公钥，切勿导入私钥。
6. 新增公钥通常只会自动应用到之后新建的开发机；已有开发机需要使用页面提供的“补注入公钥”操作或按平台管理员指引处理。
7. 对于不是通过 Zenith 新建的开发机，可能需要先在机内授权平台终端公钥。
8. 检查开发机安全组、网络路由、SSH 服务和目标端口。

删除 Zenith 中的公钥记录不会自动从已经注入的开发机中移除该公钥。需要收回访问时，还应在机内清理相应授权。

## 训练任务或推理服务问题

### 无法创建训练任务

- 只读账号不能新建训练任务。
- 学生制度账号可不选项目，但无有效正式项目资格时仅限低优；其他非平台管理员需选择有写入权限的有效项目。
- 队列、规格和可用区必须匹配。
- 镜像 URL、入口命令和挂载配置必须完整。
- 配额或月度卡时超限会拒绝新任务。

### 看不到日志

部分资源区没有向 Zenith 提供日志查询能力。页面如果显示“厂商任务控制台”链接，请使用该入口查看；没有日志按钮不代表任务没有运行。

### 推理服务功能不可用

确认当前资源区明确支持推理管理，并核对模型版本、镜像、资源规格和访问方式。云端产品存在推理能力，不代表当前 Zenith 部署一定开放创建入口。

## 镜像、模型和共享问题

### 镜像可见但拉取失败

登记只记录镜像地址或原生 ID，不会授予镜像仓库权限。检查仓库认证、网络、Tag、架构和区域，并确认该地址已在当前资源区登记且处于启用状态。

### 模型可见但无法部署

「模型」页只保存模型元数据。检查真实模型文件是否存在、存储路径是否正确、目标环境是否有权限，以及格式是否与运行镜像兼容。

### 无法撤回共享

模型的可见范围只能扩大，平台共享通常不可撤回。共享前必须在确认框中核对影响。个人和项目镜像可以移除登记，云端镜像和已运行的资源不受影响；平台镜像由平台管理员启用或停用。

## 文件分享和迁移问题

### 文件分享链接失效

分享链接有明确到期时间。记录被撤销或过期后不能重新获取原链接；已经发出的签名链接在原到期时间前仍可能有效。创建新分享前先确认数据仍适合对外提供。

### 文件迁移无法读取源路径

填写厂商实例 ID 不会自动开放开发机内部目录。源文件或目录必须已经挂载到当前环境可访问的位置，并具有读取权限。

### 文件迁移无法写入目标路径

确认目标父目录存在、可写、空间充足，并且没有不应覆盖的同名文件。目录迁移最多处理 1,000 个普通文件，符号链接会跳过。

### 任务停在“待审批”

当前环境已开启迁移审批。等待平台管理员审核，不要重复创建相同任务。需要补充说明时提供源、目标、数据用途和预计规模，但不要发送签名链接或凭据。

## 费用或用量数字与厂商账单不同

Zenith 当前费用主要按采样卡时和平台管理员维护的价表估算，用于趋势、预算和配额治理，不等同于厂商账单或发票。

差异可能来自采样粒度、价格配置、项目标签、未归属用量和厂商最终结算规则。报告问题时同时提供日期范围、资源区、GPU 型号、开发机或训练任务以及两边数字的截图。

先看开发机上的计费徽标：包内资源不消耗账号余额，也不应出现余额类警告；按量才会烧现金；计费未知不要猜成免费。余额偏低、接口“不支持”和包内队列售罄是三件不同的事。

## 提交工单前准备什么

优先使用控制台右上角 **帮助 > 提交工单**，而不是线下单独找人；进度在 **我的工单** 中查看。提交前准备：

- 你的登录名和产品身份，不要提供密码或 Token。
- 页面名称、资源区和项目。
- 资源名称及厂商资源 ID。
- 操作时间、操作名称和期望结果。
- 完整错误提示和经过脱敏的截图。
- 是否已经刷新，以及其他资源区是否正常。

不要在工单中发送云账号密钥、API Token、密码、私钥、签名下载链接或未脱敏业务数据。详见[工单与钉钉帮助](/account/feedback)。
