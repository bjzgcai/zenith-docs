# 常见问答

## Zenith 会自动选择最便宜或最空闲的资源区吗？

不会。Zenith 提供统一入口，但当前不会自动比较价格、库存和可用区并替你选择资源区。新建资源时仍需根据页面可选项和平台管理员建议选择资源区、队列、规格和镜像。

## 为什么同一个功能在不同资源区不一样？

不同资源区、账号权限和产品模式提供的能力不同。请以当前页面的按钮状态、能力标签和错误提示为准，[厂商与能力差异](/reference/vendors)只提供理解框架，不是固定能力承诺。

## 为什么我能进入页面，却不能执行操作？

产品身份决定页面呈现，平台角色决定全局操作等级，项目角色决定项目内管理范围，资源所有权保护终端、文件和破坏性操作。你可能是项目管理员，但平台角色仍为访客（只读）；也可能是普通用户，但不是目标开发机的所有者。详见[角色、身份与权限](/reference/permissions)。

## 项目是否拥有项目内的开发机？

不拥有。项目是成员、预算、配额、模板、通知和用量的聚合范围，开发机仍有个人所有者。项目的负责人或管理员只获得有限的项目管理和生命周期能力，项目标签不会转移所有权。

## 项目管理员可以打开成员开发机的终端或迁移文件吗？

不可以仅凭项目角色操作。终端、文件迁移和 SSH 公钥补注入要求开发机所有者或平台管理员，并且还要满足平台操作权限。

## 开发机上的“包内 / 按量 / 计费未知”是什么意思？

- **包内：** 包月或专属池资源，不产生现金消耗，也不会因为账号余额偏低而不可用。
- **按量：** 将产生现金消耗，创建向导会明确提示。
- **计费未知：** 云端没有给出可信计费形态。页面不会把它猜成包内或按量。

余额、配额和卡时是三套限制。包内创建失败时，先看队列容量、配额和卡时，不要先去充值。

## 为什么刚新建或停止的开发机没有立即更新？

云端处理和 Zenith 状态同步都需要时间。总览和开发机列表在页面可见时约每 15 秒刷新；进行中的文件迁移约 5 秒刷新。等待合理时间后刷新一次，并查看“数据已过期”标签和资源区连接提示。不要连续重复提交相同操作。浏览器里只有网页终端是 WebSocket，列表不会实时推送。

## “数据已过期”是不是开发机已经被删除？

不是。它表示 Zenith 最近没有再次确认该资源。资源可能仍在云端存在，也可能连接暂时不可用。应先刷新并与云端状态核对。

## 镜像和模型都支持项目共享吗？

镜像支持：资源区5 和资源区10 可以登记个人镜像，或登记为项目成员可用。模型仍只有“仅本人、平台共享”两种范围，不支持项目共享。

## 平台共享后可以撤回吗？

通常不可以。模型的可见范围只能扩大。共享前务必确认内容、许可证和底层访问权限。

## 共享模型后，其他人为什么仍然无法使用？

共享扩大的是 Zenith 中的可见范围，不会自动授予模型存储或云资源权限。还需要检查网络、存储权限、区域和运行环境兼容性。镜像同理：登记只保存引用，不会授予镜像仓库的拉取权限。

## 删除模型或版本会删除真实模型文件吗？

不会。「模型」页只管理登记元数据。删除模型或版本只移除 Zenith 中的记录，底层存储文件需要单独管理。

## 为什么撤销文件分享后，已经发出的链接仍可能下载？

签名下载链接在创建时已经带有到期时间。撤销会删除分享记录并阻止再次获取链接，但已经发出的链接可能在原到期时间前继续有效。因此分享有效期最长受限，并应只发送给可信接收者。

## 填写厂商实例 ID 后，文件迁移能直接访问开发机里的任意路径吗？

不能。表单里的源/目标厂商实例 ID 只是可选关联记录，不会自动打开开发机本地磁盘。源和目标路径仍必须已经挂载到迁移服务可访问的位置。

## 资源区6 详情里的“平台中转 · 固定端口”和网页终端是一回事吗？

不是。中转端口是给本机 `ssh` 用的固定公网端点，官方跳板跳数封装在中转内部，最终仍用开发机上的公钥认证。网页终端是浏览器里的独立会话。尚未分配中转端口时，可先用网页终端或应用链接。

## 为什么训练任务没有日志？

部分资源区没有向 Zenith 提供日志查询能力。页面如果提供“厂商任务控制台”链接，请从该入口查看任务日志或事件。没有日志入口不代表任务一定失败。

## Zenith 账单是最终结算账单吗？

不是。当前费用汇总主要依据采样卡时和平台管理员维护的静态价表估算，用于趋势、预算和治理。最终费用以平台管理员公布的结算规则和云端账单为准。

## 配额超限会自动停止正在运行的开发机吗？

不会。实例与 GPU 配额和月度卡时额度主要拦截新的创建或启动请求，不会自动停止、缩容或调整已经运行的资源。

## API Token 是否有独立权限？

没有。个人 API Token 继承账号当前的平台角色和项目关系，不会获得额外权限。明文只在创建时显示一次，应像密码一样保管，不要提交到代码仓库或工单。

## 为什么能看到“仅监控”的资源，却不能操作？

“仅监控”的资源来自平台能够读取的云端清单，其中可能包含组织并不拥有的资源。只有平台管理员在 **纳管资源** 中登记为“平台管理”的资源，以及页面明确开放的操作，才应视为可管范围。详见[资源全局监控与纳管资源](/admin/resources)。

## 什么时候应该提交工单？

完成一次刷新并核对权限、连接、能力、资源状态和参数后，问题仍持续存在时，应通过控制台右上角 **帮助 > 提交工单** 提交，并在 **我的工单** 中跟进。准备页面名称、资源区、项目、厂商实例 ID 或资源 ID、操作时间和完整错误提示；不要发送密码、私钥、Token、云账号密钥或签名链接。

如果工单被转交研发，工单里会出现 GitHub Issue 链接；没有仓库权限时以工单状态和平台管理员说明为准。详见[工单与钉钉帮助](/account/feedback)和[常见问题排查](/troubleshooting/common)。
