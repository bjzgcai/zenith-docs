# 平台简介

Zenith 是一个多云 GPU 算力管理平台。它把多个云平台的资源按资源区（资源区1–4、资源区5、资源区6、资源区10 等）接入同一个控制台，帮助用户在统一入口中查看资源、使用开发机，并管理训练、推理、镜像、模型和数据资产。

::: tip 先了解你的身份
控制台会根据平台角色、产品身份、项目角色和资源所有权显示不同页面与操作。看到某个页面，不代表当前账号一定可以执行其中的所有操作。请先阅读[角色、身份与权限](/reference/permissions)。
:::

平台管理员可在右上角 **帮助 > 项目仓库** 打开代码仓库（手机版在导航菜单底部），继续访问 Issues 和开发资料；访问仓库需要相应的 GitHub 权限。

## Zenith 解决什么问题

在多个云平台分别管理 GPU 资源时，入口、字段、状态和操作习惯通常并不一致。Zenith 提供一层统一的产品体验，让日常工作围绕“我要完成什么任务”展开，而不必先熟悉每一家云厂商的控制台。

你可以在 Zenith 中使用以下功能：

| 工作领域 | 可以做什么 |
| --- | --- |
| 计算资源 | 查看开发机，按权限新建资源，执行启动、停止等生命周期操作，并查看连接信息、状态和监控 |
| 训练与推理 | 创建和管理训练任务、推理服务，查看任务状态、节点和云端提供的访问入口 |
| 镜像 | 按资源区查看个人、项目和平台运行环境；资源区5 和资源区10 支持用户登记个人或项目镜像，平台镜像由平台管理员导入并启用 |
| 模型 | 登记模型及版本元数据，在“仅本人”和“平台共享”之间选择可见范围，并在推理部署中引用 |
| 文件与存储 | 在 **我的存储** 浏览已授权的个人存储、项目存储、公共存储和存储桶；平台管理员在 **存储管理** 中管理文件分享和跨区传输 |
| 项目协作 | 按项目聚合成员、开发机、训练任务、模板、配额、预算和用量；项目不会取代资源所有权 |
| 账户与安全 | 在 **账号设置** 中管理 SSH 密钥和 API Token，在 **我的用量** 中查看与自己相关的资源消耗 |

实际可见页面和可执行操作取决于当前账号权限、资源所有权、项目关系、资源区能力以及平台管理员完成的环境配置。

## 接入的资源区

Zenith 按资源区接入计算资源，每个资源区只锚定一条产品线，不是在平台上按量购买裸云主机：

- **资源区5：** 预付队列，配套包内文件存储。
- **资源区1–4：** 已预付的专属资源池。
- **资源区6：** 包月套餐资源池（包内开发机 + 套餐内文件系统）。
- **其他资源区：** 产品线尚未锁定；不要假定可以从本平台下付费单。

统一入口不代表各资源区提供完全相同的功能，也不会根据价格或库存自动替你选资源区、选队列。同一资源区在不同账号权限或产品模式下，也可能显示不同能力。按钮被禁用、页面显示“不支持”或某个资源区为空时，请优先阅读页面上的能力提示，不要把其他资源区的操作步骤直接套用过来。

开发机上的“包内 / 按量 / 计费未知”徽标说明会不会烧现金。包内资源不看账号余额；低余额不能解释包内创建失败。更详细的判断方式见[厂商与能力差异](/reference/vendors)。

## 不同用户看到什么

### 普通用户

普通用户从左侧 **工作台** 进入我的总览、我的开发机、我的训练任务、镜像、我的存储和数据集；**协作与支持** 下有项目、我的用量和我的工单。是否可以新建或变更计算资源，还取决于平台是否授予操作权限。

### 项目管理员

项目管理员与普通用户使用同一套菜单，「开发机」「训练任务」页可在 **我的 / 项目** 之间切换。项目管理员可以查看自己参与项目的详情，并按项目权限管理成员、模板、配额和 Webhook。对于标记到该项目的开发机，项目的负责人或管理员可以在满足平台操作权限时执行有限的启动、停止和重启操作。

项目角色不会把其他成员的开发机变成项目管理员所有。删除、重建、调整规格、打开终端、迁移文件等敏感操作仍以资源所有权和平台角色为准。

### 运维与平台管理员

运维使用 **运维**（运维资源概览、开发机管理、训练任务管理、队列管理、存储管理、镜像）和 **服务台**（项目、用户管理、工单受理、站点维护）两组菜单。平台管理员另有平台总览、平台状态、发版管理、审计日志、纳管资源、算力规格、组织管理、资源配额、额度策略、额外卡时审核、卡时监控和公告管理等页面，负责平台级工作。这些管理操作可能影响多位用户，执行前应确认目标、范围和影响。

本帮助中心只介绍控制台可见功能和安全操作原则，不包含环境凭据、私有地址或内部部署细节。

## 使用前必须理解的边界

### 统一入口不等于自动选云

Zenith 不会自动比较价格、容量或可用区并替你选择资源区。新建资源时，仍需要根据页面可选项选择资源区、规格、队列、镜像和项目。

### 页面存在不等于当前环境可用

一次操作是否可用，取决于资源区连接状态、当前产品模式、区域库存、账号权限和资源状态。请以页面显示的能力标签、禁用原因和错误提示为准。

### 项目是协作和聚合范围，不是租户或所有者

项目用于组织成员、预算、配额、模板、通知以及资源用量。开发机仍有明确的个人所有者；项目标签不会自动转移所有权，也不会让项目管理员获得他人开发机的终端或文件权限。

### 资源状态可能有短暂延迟

Zenith 会周期性同步云端状态，总览、平台状态和开发机列表在页面可见时约每 15 秒用 REST 刷新一次；进行中的文件迁移约 5 秒刷新。浏览器里只有网页终端使用 WebSocket，没有通用的实时看板推送。刚创建、启动或停止资源后，列表状态可能短暂落后于云端。请先刷新并关注“数据已过期”标签，避免连续重复提交同一操作。

启动、停止、SSH、监控和终端都使用详情中的 **厂商实例 ID**，不要用平台内部编号代替。

### 费用页面主要用于估算和治理

新建或启动 GPU 开发机、训练任务和推理服务可能产生真实云费用或消耗卡时额度。Zenith 当前的费用汇总主要依据采样用量和平台管理员维护的价表估算，不等同于云端账单或发票。最终结算以平台管理员公布的规则和云端账单为准。

### 权限会同时受到多层规则影响

平台角色决定只读、操作和管理能力；产品身份决定导航呈现；项目角色决定项目内管理范围；资源所有权保护终端、文件和破坏性操作。按钮不可见或操作被拒绝时，请按这四层逐项核对。

## 建议的阅读顺序

1. 阅读[认识 Zenith 中的资源](/resources/overview)，理解资源、项目与所有权的关系。
2. 阅读[角色、身份与权限](/reference/permissions)，确认自己可以执行哪些操作。
3. 阅读[厂商与能力差异](/reference/vendors)，了解页面提示代表什么。
4. 按任务进入[镜像](/assets/images)、[模型](/assets/models)等专题。
5. 遇到问题时先查看[常见问题排查](/troubleshooting/common)和[常见问答](/troubleshooting/faq)。

::: warning 使用真实资源会产生费用
提交创建、启动、扩容或训练任务前，请确认规格、数量、计费方式、所属项目和剩余额度。不再使用的资源应按平台管理员要求停止或释放；释放前务必确认重要数据已经保存到持久存储。
:::
