# 开始使用 Zenith

本页帮助你完成第一次登录，并建立使用 Zenith 算力平台前必须具备的基本认识。Zenith 把多个资源区的 GPU 放到同一个控制台中，但不会替你自动选择资源区或规格；页面上实际出现的选项和能力提示，才是当前环境的准确信息。

## 适用角色与界面路径

| 项目 | 说明 |
| --- | --- |
| 适用角色 | 所有已开通 Zenith 账号的用户 |
| 登录路径 | 打开平台管理员提供的 Zenith 控制台地址 |
| 登录后首页 | 左侧菜单的第一项：普通用户和项目管理员进入 **我的总览**；运维进入 **运维资源概览**；平台管理员进入 **平台总览** |
| 个人入口 | 页面右上角头像菜单 > **账号设置** |
| 常用入口 | 普通用户和项目管理员使用 **工作台** 与 **协作与支持** 两组菜单；运维使用 **运维** 与 **服务台**；平台管理员的菜单按用途分组，可折叠 |

::: tip 你看到的菜单可能与同事不同
页面入口由平台角色、用户类型、项目成员身份和当前环境能力共同决定。菜单较少不一定是系统故障，也可能是平台管理员尚未授权或相应功能在当前环境不可用。
:::

## 登录前的准备

请确认以下条件：

- 平台管理员已经为你开通账号，或已将你的钉钉身份接入 Zenith。
- 创建训练任务前确认当前资格：学生制度账号可以不选项目，无有效正式项目资格时仅限低优；其他普通账号需要有写入权限的有效项目。
- 如需创建或变更计算资源，你具备资源操作权限。只读用户仍可查看已授权页面，但不能创建、启动、停止或删除资源。
- 如需使用 SSH 或网页终端，准备一把 OpenSSH 公钥，或计划在登录后由平台生成密钥对。
- 已了解所在项目的 GPU 配额、卡时额度和费用规则。

## 第一次登录

### 使用账号密码登录

1. 在登录页输入平台管理员提供的登录名和密码。
2. 选择 **登录**。也可以在密码输入框中按 Enter；登录进行中重复按 Enter 不会重复提交。
3. 登录成功后进入左侧菜单的第一项：普通用户和项目管理员是 **我的总览**，运维是 **运维资源概览**，平台管理员是 **平台总览**。
4. 打开右上角头像菜单 > **账号设置**，确认登录名、姓名和当前视图符合预期。

### 使用钉钉登录

1. 在登录页选择钉钉扫码登录。
2. 使用已接入组织的钉钉账号完成授权。
3. 等待页面自动返回控制台。
4. 打开右上角头像菜单 > **账号设置**，核对当前账号身份。

如果登录后出现“无权访问”，点页面上的 **返回工作区** 回到你的首页，再确认目标页面要求的视图或角色。

登录成功后，浏览器会保存一条仅供当前站点使用的会话 Cookie（`zenith_session`）。控制台不会把账号密码、登录 Token 或私钥写入 localStorage、sessionStorage 或 IndexedDB。请从右上角头像菜单选择 **退出登录** 来结束服务端会话；关掉标签页本身不一定等于退出。平台管理员调整角色或禁用账号后，已有会话会被撤销，需要重新登录。

## 认识控制台

### 左侧导航

普通用户和项目管理员的左侧导航分两组，固定展开：

| 分组 | 页面 | 主要用途 |
| --- | --- | --- |
| 工作台 | 我的总览 | 查看运行中的开发机、可用卡时和我的项目 |
| 工作台 | 我的开发机 | 新建、连接和管理自己的开发机；点击任意一行进入详情 |
| 工作台 | 我的训练任务 | 新建和管理自己提交的训练任务 |
| 工作台 | 镜像 | 按资源区查看个人、项目和平台镜像，登记自己的运行环境 |
| 工作台 | 我的存储 | 浏览个人与项目文件，查看用量和挂载位置 |
| 工作台 | 数据集 | 浏览全平台共享的只读数据集 |
| 协作与支持 | 项目 | 查看所属项目，进入项目详情管理成员、卡时和存储 |
| 协作与支持 | 我的用量 | 查看个人额度和实际用量 |
| 协作与支持 | 我的工单 | 提交和跟进工单与云盘扩容申请 |

项目管理员看到的是同一套菜单，只是「我的开发机」「我的训练任务」显示为 **开发机**、**训练任务**；页面左上角可在 **我的 / 项目** 之间切换。

运维的菜单分为 **运维**（运维资源概览、开发机管理、训练任务管理、队列管理、存储管理、镜像）和 **服务台**（项目、用户管理、工单受理、站点维护）。平台管理员的菜单按 **平台运维、算力、存储与数据、账号与组织、卡时、服务台、预览功能** 分组，当前页面所在的组会自动展开。

### 页面右上角

- **帮助**：打开 **帮助中心**、**提交工单** 或 **加入钉钉群**。
- **通知铃铛**：汇总公告、版本信息和与你相关的提醒；底部的 **查看全部公告** 打开公告页。
- **外观**：在亮色、暗色和跟随系统之间切换。
- **视图**（平台管理员和运维）：切换到其他视图查看对应的菜单与页面。
- **头像菜单**：**账号设置**（个人资料、SSH 密钥、API Token）和 **退出登录**；运维和平台管理员在这里还有 **我的工单**。

通知的已读状态保存在当前浏览器中，不会在不同设备或不同浏览器之间同步。

## 理解三类角色

Zenith 中有三套用途不同的角色，请不要混用：

| 权限维度 | 常见值 | 决定什么 |
| --- | --- | --- |
| 平台角色 | 访客（只读）、普通用户、运维、平台管理员 | 能否读取数据、变更资源或管理系统 |
| 视图 | 用户视图、项目管理员视图、运维视图、平台管理员视图 | 可以进入哪些控制台页面 |
| 项目角色 | 负责人、管理员、成员、只读 | 能否管理某一个项目的成员、卡时和存储 |

例如，一个普通用户可以同时是某个项目的成员；他能够操作自己有权使用的资源，但不能修改该项目的成员或额度。

::: warning 页面按钮不是最终授权依据
有些页面会提前隐藏或禁用不可用操作，也有些操作会在提交后再校验。最终结果以页面返回的权限提示为准。不要因为看到了按钮，就假定账号一定可以执行该操作。
:::

## 完成首次设置

建议按以下顺序完成准备：

1. 打开 **协作与支持 > 项目**，确认已经加入正确项目；所属组织和配额在 **我的用量** 中查看。
2. 打开头像菜单 > **账号设置** > **SSH 密钥**，导入已有公钥或生成一把新密钥。
3. 在项目详情的 **卡时** 页查看项目额度。
4. 打开 **工作台 > 我的总览** 确认可用卡时，再到 **我的开发机** 点击 **新建开发机**，在弹窗中检查是否有可用算力规格（GPU 型号和卡数）。普通用户只选择资源区，不选择队列。
5. 查看卡时配额和规格说明，确认计划使用的 GPU 类型仍有参考余量。
6. 阅读[快速开始](/guide/quick-start)，完成第一次开发机创建和连接。

SSH 密钥的完整说明见[连接开发机](/compute/connection)，资源之间的关系见[认识 Zenith 中的资源](/resources/overview)。

## 如何判断首次登录成功

满足以下条件即可认为首次登录和基础准备已完成：

- 页面已经进入与你身份相符的首页，且右上角能够显示你的账号信息。
- 能够打开与你身份相符的菜单页面。
- **我的用量** 能够显示正确组织；没有组织时已经联系平台管理员确认。
- **账号设置 > SSH 密钥** 能够显示已导入或新生成的公钥记录。
- **项目**页面能够显示你有权查看的项目；如果没有项目，也已经向平台管理员确认是否允许无项目使用开发机。

登录和导航信息通常立即生效。角色或项目成员关系刚被调整后，如页面仍显示旧状态，请退出后重新登录；资源列表本身可能按页面规则延迟刷新。

## 数据刷新与状态延迟

- 总览、平台状态和开发机列表在浏览器标签页可见时约每 15 秒刷新一次；后台刷新不会让按钮转圈。
- 进行中的文件迁移约每 5 秒刷新进度；其余时间约 15 秒。
- 开发机的云端状态通常需要一个同步周期才能反映到 Zenith，实际可能约 30 秒或更久。
- 切换到其他浏览器标签页时，部分页面会暂停常规刷新；返回后会重新获取。
- 训练任务、推理服务和工作台中的部分列表主要在进入页面、执行操作或点击 **刷新** 时更新。
- 浏览器里只有网页终端使用 WebSocket；列表和监控都是 REST 拉取，不会持续推送。
- 启动、停止、SSH、监控和终端都依赖详情中的 **厂商实例 ID**。名称下方的厂商实例 ID 才是操作标识，不是平台内部编号。
- “数据已过期”表示 Zenith 最近没有再次确认该资源；它不表示资源已经被自动删除。

提交创建、启动或停止后，请先等待状态变化，避免连续重复点击。

## 安全与费用提醒

::: warning 创建资源可能立即产生费用
开发机、训练任务和推理部署可能消耗卡时，按量档位还会产生现金消耗。提交前核对规格、GPU 数量、计费徽标（包内 / 按量 / 计费未知）和所属项目。包内资源不看账号余额；余额偏低不能用来解释包内创建失败。
:::

- 不要在开发机名称、描述、启动命令或公开资产说明中填写密码、访问密钥或其他凭据。
- 私钥只应保存在你控制的安全位置，不要上传到模型、镜像或共享文件中。
- 删除开发机、训练任务或部署前，先把需要保留的数据写入持久存储。
- 项目归属用于统计、配额和通知，不会把云端资源所有权转移给项目。
- 控制台的费用估算不等同于云厂商正式账单。

## 常见问题

### 为什么我没有“开发机管理”菜单？

该页面面向运维和平台管理员。普通用户在 **工作台 > 我的开发机** 查看和操作自己的开发机；项目管理员在 **开发机** 页切换到 **项目** 查看所管理项目的开发机。

### 为什么某个资源区没有训练、监控、镜像或存储入口？

不同资源区和计算模式支持的能力不同。请以页面能力提示和可选项为准；如果入口突然不可用，先查看页面连接提示，再提交工单。

### 刚创建或停止资源，为什么状态没有变化？

操作提交成功只表示请求已被接受。云端执行和状态同步都需要时间，请等待一个或多个刷新周期并点击 **刷新**，不要立即重复提交。

### 登录后显示的信息不完整怎么办？

先刷新页面或重新登录。如果账号、用户类型、项目成员身份仍不正确，请通过工单把页面显示的账号名、目标页面和发生时间提供给平台管理员，不要发送密码或私钥。

## 表格排序

带排序箭头的列可以点击标题，在降序、升序和原始顺序之间切换。名称、状态、时间、数量、容量和卡时等数据列均可按页面提供的列排序；操作按钮列不参与排序。数值按实际大小比较，空值不会当作 0。

列表默认每页 20 条，可切换为 10/20/50/100；搜索框在全部记录中查找，而不只是当前页。普通表格先对已加载的全部记录排序，再分页展示。开发机管理和审计日志由服务端对全部查询结果排序。分批加载的对象列表只排序已加载部分；用户详情 › 卡时中的分配记录和上交记录超出上限时标注“仅显示最近 N 条”，排序只覆盖已显示的记录。

平台管理员的 **用户管理** 会分批加载全体用户的卡时摘要，加载完整后即可按“个人卡时”列（个人剩余卡时）跨页排序。
