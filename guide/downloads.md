# 下载文档与离线阅读

打开任意帮助文章，在正文上方的 **下载本文** 中选择 **Markdown** 或 **PDF**。每次下载保存当前这一篇文章；需要其他文章时，打开对应页面再下载。

## Markdown

Markdown 文件适合用文本编辑器阅读、整理笔记，或交给支持 Markdown 的工具使用。文件保留标题、列表、表格和代码示例，提示框与折叠说明也会导出。

文档链接和图片地址指向当前帮助站点。查看图片、访问关联文章时仍需联网；如果希望连同图片一起离线保存，请选择 PDF。

## PDF

PDF 文件可以直接下载，用 PDF 阅读器打开或打印。文件包含文章的文字、图片、表格、代码及展开后的折叠说明，不包含网站导航栏和操作按钮。

PDF 中的关联文章名称保留为文字，需要进一步阅读时请回到帮助中心打开对应文章。外部参考链接仍可点击，访问时需要联网。

下载文件是保存时的版本，不会自动更新。操作平台前，请回到帮助中心核对最新说明；实际可用入口和权限以当前控制台为准。
