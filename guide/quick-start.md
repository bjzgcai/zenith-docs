# 快速开始：创建并连接开发机

本教程带你完成一条最常用的使用路径：准备 SSH 公钥、通过工作台创建开发机、打开网页终端，并在使用结束后停止或释放资源。

## 适用角色与界面路径

| 项目     | 说明                                                   |
| -------- | ------------------------------------------------------ |
| 适用角色 | 具备资源操作权限的普通用户或项目管理员                 |
| 只读用户 | 可以查看已授权资源，但不能完成创建、停止或删除步骤     |
| 创建路径 | **工作台 > 我的开发机 > 新建开发机**                   |
| 密钥路径 | **头像菜单 > 账号设置 > SSH 密钥**                     |
| 连接路径 | **工作台 > 我的开发机 > 终端**                         |

普通用户只选择资源区、GPU 型号和卡数，不挑选队列。若组织尚未分配算力规格，请联系平台管理员。运维和平台管理员在 **开发机管理** 中使用「新建开发机（按资源区规格）」向导，说明见[开发机管理](/compute/instances#按资源区规格新建开发机)。

## 开始前检查

- 账号能够正常登录。
- 账号具备资源操作权限。
- 工作台已分配可用算力规格（GPU 型号和卡数）。
- 计划使用的项目处于有效状态，且配额、卡时额度未耗尽。
- 所选规格仍有镜像可选；创建窗口会展示不含厂商资源标识的实时参考余量，最终以创建结果为准。
- 如需 SSH，已经准备 OpenSSH 公钥；如使用平台生成密钥，已经准备安全保存私钥。

::: warning 先确认数据保存位置
开发机删除后通常无法恢复本地数据。长时间保留的数据应写入个人存储、项目存储或挂载盘等持久存储，不要只保存在开发机的临时系统盘中。
:::

## 第 1 步：登记 SSH 公钥

1. 打开右上角头像菜单 > **账号设置** > **SSH 密钥**。
2. 选择以下任一方式：
   - **导入公钥**：填写可识别的名称，粘贴 OpenSSH 单行公钥。
   - **生成密钥对**：由 Zenith 生成 Ed25519 密钥对。
3. 如果选择生成密钥对，立即复制或下载私钥。关闭结果窗口后无法再次查看私钥明文。
4. 确认密钥出现在列表中；“默认”目前只是列表中的管理标记，自动补注入仍会读取全部登记公钥。

平台只保存公钥，不代你保管私钥。详细规则见[连接开发机：管理 SSH 密钥](/compute/connection#管理-ssh-密钥)。

## 第 2 步：选择快速创建配置

1. 打开 **工作台 > 我的开发机**，点击右上角的 **新建开发机**。
2. 在弹出的创建窗口中填写或确认：

| 字段            | 如何选择                                                                                                   |
| --------------- | ---------------------------------------------------------------------------------------------------------- |
| 名称            | 使用便于识别且不包含敏感信息的名称                                                                         |
| 型号 / 卡数     | 先选 GPU 型号，再选卡数；实际队列和规格由平台管理员配置的路由决定                                          |
| 容量快照        | 窗口可见时约每 15 秒刷新参考余量，样本最多缓存 60 秒，超过 90 秒标为过期；“可能排队”不等于已经取得队列位置 |
| 镜像            | 保留规格默认镜像，或搜索 / 按 python、pytorch、ubuntu 等标签筛选该规格当前可用的平台镜像                   |
| 所属项目        | 用于用量、配额和通知归集；不会自动改变资源区或规格                                                         |
| 个人存储 / 项目存储 | 仅在组织、项目和所选镜像都允许时出现；个人存储的目录名来自账号的存储标识，不是登录名。资源区1–4 暂不提供这两项 |
| 挂载盘          | 仅当平台管理员已分配挂载盘时出现，可多选                                                                   |
| 公网 SSH        | 仅在确实需要从公网连接且环境支持时开启                                                                     |

3. 查看弹窗下方的规格说明和“将挂载”提示，确认符合预期。
4. 再次确认 GPU 数量、项目额度，以及行上将出现的计费徽标。包内开发机不消耗账号余额。

Zenith 不会自动比较各资源区的价格或库存后替你选择；平台按平台管理员启用的队列顺序解析实际创建位置。

::: info 资源区1–4 与资源区6 的当前连接、存储方式

- 资源区1–4 当前 A100 专属池按每卡 `12 核 + 120GB 内存 + 80GB 显存` 线性组合；选择多卡是新建一台多卡开发机，不是多台开发机。池已预付，开发机配置显示为 ¥0/时。当前不提供本地盘，25--50GB 系统盘为非持久存储；只有公共存储，个人存储和项目存储暂不可用。若平台终端公钥尚未预置，新建仍会完成，但可从开发机详情打开 JupyterLab 应用链接。
- 资源区6 只允许选择所选资源池明确授权的挂载盘；没有候选时可直接无挂载新建。若详情显示的是 `10.x` 内网 SSH，Zenith 会禁用不可达的网页终端，请改用详情中的“平台中转 · 固定端口”连接。Code Server/JupyterLab 需在开发机内启动并配置监听端口后才会显示应用链接。
  :::

## 第 3 步：提交创建

1. 点击 **新建**。
2. 等待提交成功提示；弹窗会自动关闭，列表上方显示创建进度提示。
3. 不要因为列表尚未出现开发机而再次点击新建。
4. 在“我的开发机”标题右侧点击 **刷新**，等待新开发机出现。

::: tip “已提交”不等于“已运行”
提交成功表示创建请求已经被接受。开发机从排队中、启动中变为运行中还需要云端处理和状态同步，通常至少需要一个同步周期，也可能因库存、镜像或网络而更久。
:::

## 第 4 步：等待开发机就绪

新开发机出现在“我的开发机”后，观察其状态：

- **排队中或启动中**：继续等待，不要重复创建。
- **运行中**：计算资源已经运行，可以继续获取 SSH 信息或打开终端。
- **失败或异常**：打开详情查看状态说明，根据页面提示修改配置或提交工单。
- **数据已过期**：当前记录不是最新确认结果，先刷新详情，再决定是否操作。

新建成功后，开发机列表可能约 30 秒后才出现或更新。工作台在页面可见时约每 15 秒静默刷新，并会在提交后约 5 秒和 35 秒补拉；切回页面时会立即刷新，你也可以手动点击刷新。启动或停止命令接受后，列表会先显示“排队中”或“停止中”，并在约 2 秒和 6 秒补拉。项目管理员还可在 **开发机** 页切换到 **项目** 查看所管理项目的开发机。新记录名称下方会显示厂商实例 ID，之后的终端和 SSH 都依赖它。

## 第 5 步：连接开发机

1. 等待开发机处于 **运行中**。
2. 打开开发机详情，优先选择页面显示为可用的入口：**打开终端**、**打开 JupyterLab**、**打开 Web 应用预览**或 **打开 TensorBoard**。
3. 使用终端时等待状态变为 **已连接**；使用厂商应用链接时按提示完成对应厂商登录。
4. 进入环境后执行简单的只读命令，确认当前目录和运行环境可用。

如果终端提示未授权：

1. 打开开发机详情。
2. 在连接详情的“我的公钥”中查看注入状态。
3. 在权限和环境允许时选择 **补注入公钥**。
4. 等待注入成功后重新打开终端。

终端断开后，可以选择 **重新连接**建立一个新会话；不能恢复已经断开的旧会话及其屏幕状态。长时间运行的工作建议使用镜像中可用的会话保持工具，或提交为训练任务。

如果详情明确标注“内网 SSH”或“未启用 SSH”，不要重复打开终端：内网端点需要专网路由，
而资源区1–4 的云端子账号公钥权限不足时，开发机只启用 JupyterLab。此时使用详情上方的应用链接。

更多说明见[连接开发机](/compute/connection)。

## 第 6 步：保存工作结果

在停止或删除开发机前：

1. 将代码提交到受控代码仓库。
2. 将数据、模型和检查点写入持久存储。
3. 确认写入完成，并从另一个入口验证关键文件可见。
4. 不要把访问密钥写入镜像、模型版本、共享目录或命令历史。

## 第 7 步：停止或删除开发机

### 暂时不用：停止

1. 确认任务已经结束且数据已保存。
2. 在“我的开发机”选择 **停止**。资源区1–4 会额外提示：系统盘在停止后可能丢失未挂载数据。
3. 等待提示请求已提交。
4. 稍后刷新列表，确认状态变为 **已停止**。

停止能否完全停止计费取决于资源区和资源类型；仍可能保留磁盘、网络或其他资源费用。

### 不再需要：删除

1. 再次确认数据已有独立备份。
2. 选择 **删除**。
3. 阅读确认框后确认操作。
4. 等待列表刷新，确认资源进入删除中、已删除或从当前列表消失。

删除通常不可恢复。页面提示已下发删除请求时，云端仍可能处于处理阶段，请勿重复提交。

## 成功判断与刷新延迟

完成下列检查即可认为快速开始成功：

| 阶段       | 成功判断                             | 可能的延迟                 |
| ---------- | ------------------------------------ | -------------------------- |
| SSH 密钥   | 密钥记录出现在 SSH 密钥列表          | 通常立即显示               |
| 创建请求   | 页面显示创建请求已提交               | 通常立即显示               |
| 开发机就绪 | 开发机出现在“我的开发机”且状态为运行中 | 常见为约 30 秒或更久       |
| 网页终端   | 状态显示“已连接”，可以输入命令       | 通常数秒；密钥注入可能更久 |
| 停止或删除 | 刷新后状态发生变化                   | 一个或多个状态同步周期     |

## 风险提示

- 快速创建仍会使用真实云资源，可能立即消耗 GPU 配额和产生费用。
- 队列余量、报价或配额预检查都是提交前参考，最终仍可能因实时库存和厂商校验失败。
- 公网 SSH 会扩大开发机网络暴露面。能使用内网连接或网页终端时，不要无必要开启公网访问。
- 删除开发机可能永久丢失本地数据；停止开发机也不保证所有附属费用归零。
- 项目归属仅用于平台统计、额度和通知，不代表项目获得云端资源所有权。

## 常见问题

### 工作台没有可用算力规格怎么办？

普通用户不能手选队列。请联系平台管理员为组织分配算力规格。运维和平台管理员可在 **开发机管理** 使用按资源区规格新建的向导，但不要随意填写不确定的规格或可用区标识。

### 新建后为什么看不到开发机？

先等待约 30 秒，再点击“我的开发机”右上角的刷新按钮。若仍未出现，检查提交提示是否报错，并确认没有因配额、库存或权限被拒绝。

### 开发机运行了，但“终端”无法打开？

先确认详情已显示厂商实例 ID，再检查厂商能力提示、端点是中转/公网还是仅内网、开发机是否属于允许的平台队列，以及“我的公钥”注入状态。已有开发机可能需要执行“补注入公钥”。资源区6 若显示“平台中转 · 固定端口”，请用该命令而不是内网地址。

### 为什么 SSH 只能显示内网？

当前开发机可能未启用公网连接，或环境不支持公网端点。内网地址只能在可达的网络环境中使用；不要尝试绕过平台管理员设置。

### 我应该停止还是删除？

近期还会继续使用且需要保留开发机环境时，优先停止；确认不再使用且数据已备份后再删除。实际费用差异以平台和所在资源区的计费规则为准。更多决策方法见[开发机使用与生命周期最佳实践](/compute/instance-lifecycle)。

### 如何选择合适的镜像？

优先选择平台已启用、与目标代码版本匹配的镜像。创建窗口可以按类别、版本筛选，也可以搜索名称或原生地址。选择资源区专属镜像后，平台会按该镜像所属资源区路由。详见[如何选择合适的镜像](/assets/choosing-images)。
