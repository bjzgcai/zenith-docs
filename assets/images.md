# 镜像

镜像页面按资源区展示 **平台镜像、个人镜像、项目镜像**。平台镜像由平台管理员 **导入**，个人和项目镜像由用户 **登记**（从开发机保存的镜像自动成为个人镜像）。登记保留云平台的完整地址；各资源区的镜像互不相通，同一地址在不同资源区需要分别登记。

::: tip 不知道选哪个镜像？
新建开发机或训练任务前，先阅读[如何选择合适的镜像](/assets/choosing-images)，了解如何根据 CUDA、PyTorch、训练框架和项目需求选择正确的镜像。
:::

## 查看镜像

1. 打开侧栏 **镜像**，选择资源区。
2. 用来源分段 **全部 / 平台 / 我的 / 项目** 筛选，再搜索名称、地址或项目名。搜索覆盖当前资源区的全部镜像，不只是当前页；资源区、来源和搜索词会写进地址栏，可以收藏或分享。
3. 「适用」列标出镜像能否用于 **开发机**、**训练任务**；划线的标签表示不可用，悬停可看原因。
4. 新建开发机或训练任务时，在相同资源区选择自己有权使用的镜像。平台停用的镜像不再出现在新建窗口。

::: info 镜像的适用场景
部分资源区（例如资源区10）为不同用途提供了不同的预置镜像：有的只适用于开发机，有的只适用于分布式训练。为使各资源区体验一致，Zenith 按适用场景过滤新建窗口的镜像列表。
平台管理员可在平台镜像行的 **更多 › 设置适用场景…** 中分别勾选 **开发机**、**训练任务**；保存前会确认影响。取消勾选后该镜像不再出现在对应流程的新建窗口，另一个流程不受影响。仅适用于在线服务等其他用途的镜像可以两个都不勾选。
你自己登记的个人、项目镜像，以及从开发机保存的镜像默认在两种场景下都可用。例外：资源区10 无法拉取资源区5 开发机保存的私有镜像，这类镜像在资源区10 会标为不可用。
:::

## 登记个人或项目镜像

资源区5 和资源区10 开放 **登记镜像**；其他资源区的按钮置灰并说明原因。运维视图的镜像页只能查看。

1. 在 **镜像** 页面选择资源区，点击 **登记镜像**。
2. 粘贴完整容器镜像地址，例如 `registry.example.com/team/env:v1`。格式为 `域名/路径:版本`（或 `@sha256:` 摘要），不要带 `https://` 或用户名、密码。
3. 可选填显示名称，类型选择 **个人镜像（仅本人可用）** 或 **项目镜像（项目成员可用）**。选择项目镜像后才会列出你已加入且可以登记镜像的活跃项目；项目角色为只读的成员可以使用项目镜像，但不能登记。
4. 点击 **登记**。提交期间对话框不能关闭；失败时对话框保留你填写的内容。登记成功后列表会切到对应资源区并清除筛选，新镜像立即可见。返回新建开发机或训练任务窗口，选择相同资源区并点击 **刷新镜像**，即可选择登记的环境。

同一地址再次登记到同一类型时不会重复创建，原显示名称保持不变。

登记不需要平台管理员审批，但也不替你取得镜像仓库的读取权限。请先在云端确认目标资源池能拉取镜像；私有仓库的凭据应由平台管理员通过云端配置。

自己维护的登记可在行的 **更多 › 移除** 中移除，移除前会确认。此操作不删除云端镜像，也不改变已经运行的开发机或训练任务，需要时可重新登记。失去项目成员身份后，不能继续通过该项目的登记新建资源。

## 保存开发机为镜像

在 **我的开发机** 中打开自己的开发机详情，在 **设置** 中找到 **保存为镜像**。

- **资源区10**：平台管理员配置好目标镜像仓库后，填写镜像名称并点击 **保存镜像**。开发机须处于运行中，保存期间请勿停止或重启，也应避免安装软件或修改文件。平台会显示保存进度；刷新页面后仍可继续查看。保存成功后自动加入你的个人镜像，可在资源区10 新建开发机或训练任务时选择。每次保存使用独立地址，避免覆盖已有镜像。
- **资源区5**：同样可以直接点击 **保存镜像**，平台使用已配置的开发机镜像归档仓库。开发机须运行中且没有其他镜像构建。保存成功后自动加入你的个人镜像，可在资源区5 新建开发机或训练任务时选择。

提交后按钮会锁定，直到保存记录出现在 **最近 10 次保存** 中（最长约 1 分钟），避免重复保存。保存成功的记录带 **去镜像页查看** 链接（平台管理员替他人保存时不显示，镜像加入所有者的个人镜像）。只读账号可以查看保存记录，但不能发起保存。

两个资源区都使用 Zenith 已配置的云账号，无需你填写仓库密码。镜像归属及个人、项目可见范围由 Zenith 管理；仓库的临时认证由平台自动获取和续期。

保存的是开发机软件环境，挂载存储里的数据不会存进镜像，请不要把保存镜像当作文件备份。显示 **确认中** 时请勿重复保存，平台会继续核对。若镜像保存完成但个人登记失败，记录会分别说明结果。

云端官方说明：资源区10 见[创建开发机镜像制作任务](https://cloud.baidu.com/doc/AIHC/s/rmbkpkt4x)，资源区5 见[构建自定义镜像](https://docs.volcengine.com/docs/ml-platform/build-custom-container-image?lang=zh)。

## 平台管理员导入平台镜像

1. 在 **镜像** 页面选择目标资源区，点击 **导入平台镜像**。
2. 资源区5 和资源区10 先选择预置镜像仓库，再查看该仓库的标签；其他资源区读取云端的完整镜像目录（逐页读到底，最多 2000 个）。
3. 搜索并勾选需要使用的镜像或标签，也可以用 **全选当前结果**。选择不会自动覆盖整个仓库，也不会自动导入以后新增的标签。
4. 点击 **导入 (N)** 并确认（N 不含已导入的项）。通过目录选择的镜像会先核对来源，再加入当前资源区。
5. 完成提示会写明「已导入 N 个镜像，M 个已存在」。已存在的项不会重复创建；已停用的项须在列表中重新启用。

只勾选组织准备使用的环境。计划废弃、过旧或不需要的标签可以直接不选。

标签按数字分段从高到低排列，例如 `v0.18.0 → v0.17.0 → v0.11.2`，`2.10.0` 排在 `2.9.0` 前。搜索会匹配名称、标签和完整地址；已导入的镜像也必须匹配搜索内容才会显示，不会额外排在结果前面。匹配的已导入项会标记 **已导入**，不能重复勾选。

资源区5 使用镜像目录返回的完整容器地址；其他资源区可能使用原生镜像 ID。导入不需要另填一套平台名称、版本、用途或同步状态，也不修改云端镜像。

通过目录导入时，目录离线或无法核对所选项不会留下部分结果。修复连接或刷新目录后再重试。

### 资源区10（百度百舸）

1. 选择 **资源区10**，点击 **导入平台镜像**。对话框默认进入 **按地址导入**。
2. 在百舸控制台「镜像」页找到需要的镜像和版本，把完整地址**逐行粘贴**（每行一个，最多 100 个），例如 `ccr-registry.baidubce.com/aihc/aibox-cuda:13.3.1-cudnn-devel-ubuntu24.04`。每行须包含仓库域名，并以 tag 或 `sha256` 摘要结尾。
3. 已导入过的地址会在输入框下方标出，提交时自动跳过，确认框会写明跳过的数量。点击 **导入 (N)** 并确认。`ccr-registry.baidubce.com/...` 这类内网地址直接导入：镜像最终由资源区10 的机器在内网拉取，平台不需要也无法列出它的标签，因此不必修改接入节点配置。`registry.baidubce.com/...` 的公网地址会实时向公网 registry 核对 tag，写错的 tag 会被拦下；其他自建地址则与资源区10 接入节点目录文件的 `images` 列表核对，核对失败时整批不会导入。

也可以切换到 **预置镜像仓库**，从运维配置的清单里勾选版本。清单由运维在资源区10 接入节点的目录文件中通过 `presetImageRepos` 维护，以百舸控制台「镜像」页显示的地址为准（例如 `inference/aibox-ubuntu`、`inference/sglang`、`inference/vllm-openai`），该清单之外的仓库不会出现在这个下拉里（按地址导入时仍会实时核对 tag）。若「选择镜像仓库」为空，对话框会提示改用 **按地址导入**：这通常说明 `presetImageRepos` 尚未配置，或修改后未重启接入节点（目录文件只在启动时读取一次）。预置仓库的标签会实时向公网 registry 核对，核对失败时整批不会导入。

此入口不接受仓库用户名或密码：私有仓库的访问权限须提前在云端配置，导入既不复制镜像，也不授予拉取权限。

导入只核对标签是否存在，不验证镜像能否成功启动。平台管理员须确保资源区10 的资源池具有相应的网络和镜像拉取权限。参考资源区10（百度百舸）官方的[训练镜像选择说明](https://cloud.baidu.com/doc/AIHC/s/Tlib5k9l1)和[海外镜像拉取说明](https://cloud.baidu.com/doc/AIHC/s/ymmt2wr7j)。导入完成后，用户可在资源区10 新建开发机或训练任务时选择已启用的镜像。

## 停用与重新启用

平台管理员视图的镜像列表多一列 **状态**。关闭开关即 **停用**：确认后，新建资源无法选择此镜像；如果它是某规格的默认镜像，该规格也将无法新建。打开开关即重新 **启用**，立即生效。停用不会删除云端镜像，也不会改变正在运行的开发机或训练任务。停用和适用场景只影响平台目录，平台管理员和运维 **按厂商参数新建** 时按云端目录选择镜像，不受影响。

平台管理员视图中的 **我的 / 项目** 只列出本人可见的登记，不是全平台的登记清单。

同一镜像地址在不同资源区需要分别登记。一个资源区的启停状态不会影响另一个资源区。

## 配置默认镜像

平台管理员在 **算力规格** 的路由配置中，从对应资源区的已启用镜像里选择开发机或训练任务默认镜像。默认值也须属于当前已启用的清单；停用前应检查相关路由并更新默认值。

新安装或升级后，先导入需要的镜像，再核对路由默认值。平台不会自动把旧配置或云端的全部标签加入清单。

如果新建开发机或训练任务时镜像列表为空，先检查对应资源区是否已经导入并启用镜像。规格里填过默认地址，也仍需导入该地址。平台管理员完成导入后，点击新建弹窗中的 **刷新镜像**；默认镜像会自动选中，无需重新打开弹窗。

## 使用限制

登记只保存引用。镜像架构、开发机或训练任务的运行要求、网络和拉取权限仍由目标平台决定；登记成功不等于已经完成启动测试。

新建开发机或训练任务时，平台按资源区和当前账号重新核对镜像：允许已启用的平台镜像、本人登记的个人镜像，以及当前仍有成员身份的项目镜像。手工绕过登记、借用他人的私有登记、跨资源区使用都不会通过。

镜像登记不复制镜像，也不做跨资源区适配。系统盘快照和镜像仓库凭据不在此页面管理。
