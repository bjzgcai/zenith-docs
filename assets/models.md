# 模型

「模型」页位于侧栏 **预览功能 › 模型**，目前仅平台管理员可用，页面顶部带「预览」标签。页面分三个标签页：

| 标签页 | 内容 |
| --- | --- |
| 平台模型 | 平台登记的模型及其版本、存储路径和可见性 |
| 资源区10 模型 | 资源区10 云端模型注册表中的模型与版本 |
| 资源区10 工作流 | 资源区10 的工作流及其运行记录 |

标签页与地址栏 `?tab=` 同步（`platform`、`zone10-models`、`zone10-workflows`），可直接分享链接。原「模型仓库」「模型与工作流」「共享广场」三个入口已合并到这里，旧链接会自动跳转。

::: warning 平台不保存模型文件
「平台模型」只登记模型名称、版本和存储路径等元数据，不会上传或复制模型权重。登记前请先把文件放到可用的存储中，并确认后续工作负载有权读取。
:::

## 平台模型

### 查找模型

- 搜索框在全部模型中按名称、描述、框架或所有者查找，不只搜当前页。
- 用「框架」「可见性」筛选；可见性选「平台共享」即可看到公开模型。
- 搜索词和筛选会写入地址栏，刷新或分享链接后保持不变。
- 点击模型名称打开详情抽屉，查看描述和全部版本。

### 登记模型

1. 点击 **登记模型**。
2. 填写模型名称、首个版本号和存储路径（必填），按需补充框架、任务类型、描述和权重格式。
3. 选择可见性：「私有」或「平台共享」。
4. 点击 **登记**。必填项未填时，弹窗底部会提示缺少的字段。

选择「平台共享」时，表单下方和提交前的确认框都会提示：**共享后所有用户可见，不能改回私有**。

### 编辑模型

所有者和平台管理员可在列表中点击 **编辑**，修改框架、任务类型和描述。模型名称不可修改；可见性通过 **共享** 单独调整。保存失败时弹窗保持打开，已填内容不会丢失。

### 登记新版本

在详情抽屉的「版本」区块点击 **登记新版本**，填写版本号、存储类型、存储路径，以及可选的权重格式和说明。版本号在同一模型内唯一。

Zenith 不会检查路径中的文件是否完整，也不会自动授予读取权限。

### 可见性

| 可见性 | 谁可以看到 | 能否改回 |
| --- | --- | --- |
| 私有 | 所有者和平台管理员 | 可改为平台共享 |
| 平台共享 | 平台内所有用户 | 不能改回私有 |

列表中私有模型的 **共享** 按钮与登记时选择「平台共享」使用同一条确认。模型暂不支持项目内共享。

### 删除模型或版本

- 删除模型会同时删除其全部版本登记；删除版本只删除该版本的登记。
- 两种操作都**不会删除存储中的模型文件**，删除前会二次确认。
- 删除某个模型时，只有正在查看该模型的详情抽屉会关闭。

## 资源区10 模型与工作流

这两个标签页直接读写资源区10 的云端注册表，与「平台模型」相互独立。

- 尚未配置模型存储桶时不能新建模型，页面会显示提示。
- 新建或编辑工作流时，逐行填写任务步骤（名称、启动命令、依赖步骤）和存储挂载（文件存储、子路径、挂载路径、是否只读），无需手写 JSON；步骤名称重复、依赖缺失或形成循环时，弹窗底部会提示并禁止保存。
- 每个操作都有各自的确认说明（删除模型会同时删除其全部版本；停止运行会中断正在执行的步骤；重试会按原模板重新完整运行一次）。
- 云端仍在处理上一个操作时，页面显示「处理中」，所有写操作暂时不可用，完成后自动刷新；「版本」「运行记录」等查看操作不受影响。
- 只有排队中或运行中的运行记录可以停止；未结束的记录（含停止中）不能删除，需等它结束。
- 编辑工作流时，存储挂载的挂载路径不能重复。
- 运行中的记录每 5 秒自动刷新一次状态。

## 常见问题

### 平台模型已共享，但其他用户无法使用

共享只扩大登记记录的可见范围。还需检查底层存储权限、挂载方式、模型格式和目标资源区能力。

### 推理部署会自动使用平台模型吗？

不会。推理服务的新建向导中「参考模型路径」只用于显示所选模型最新版本的存储路径，方便复制到启动命令，不会把模型与部署关联。详见[推理服务](/workloads/inference)。

### 删除登记后文件仍然存在

这是正常行为。平台模型只管理元数据，真实文件需要在存储中单独处理。
