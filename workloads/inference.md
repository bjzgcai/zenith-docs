# 推理服务

::: warning 预览功能
推理服务位于侧栏 **预览功能 › 推理服务**，页面顶部带「预览」标签，目前**只对平台管理员开放**。查询已在真机验证，新建、启动、停止和删除尚未完成真机验证；当前版本也没有持久化推理资源的所有权，因此不向普通用户或项目管理员开放。
:::

Zenith 将推理资源分为「服务」和「部署」：

- **服务**是稳定的流量入口，保存网络、端口和流量模式等信息。
- **部署**位于服务之下，定义镜像、命令、队列、规格、可用区、副本和优先级，实际占用计算资源。

一个服务可以包含多个部署。停止服务会影响其下全部流量和副本，停止单个部署只影响该部署。

## 适用角色与入口

| 项目 | 说明 |
| --- | --- |
| 页面路径 | **预览功能 › 推理服务** |
| 查看、新建、启动、停止和删除 | 平台管理员 |
| 资源区 | 只列出支持推理的资源区；只有一个时不显示切换 |

## 查找推理服务

- 列表按页从云端读取，可改每页条数并翻到全部记录。
- 搜索框按服务名称在云端查找；「状态」筛选可选服务中、已停止、未部署。
- 点击服务名称打开详情抽屉，抽屉内有独立的 **刷新**。

| 状态 | 说明 |
| --- | --- |
| 服务中 | 流量入口处于服务状态；还应检查部署的可用副本 |
| 已停止 | 服务已停止，计算副本应已释放 |
| 未部署 | 服务还没有可用部署 |
| 启动中、停止中、删除中等 | 云端正在变化，此时不提供启停和删除操作 |

服务显示「服务中」不等于每个部署都健康，请同时查看部署状态和可用副本。

## 新建推理部署

点击 **新建推理部署**，按两步向导完成配置。向导会单独读取全部服务和平台模型，不受列表当前筛选和页码影响。

### 第 1 步：服务

- **已有服务**：从全部服务中选择要接入的流量入口。
- **新建服务**：填写服务名称和可选描述。没有任何服务时默认选这一项。

### 第 2 步：部署配置

| 字段 | 说明 |
| --- | --- |
| 部署名称 | 必填，标识本次部署或版本 |
| 参考模型路径 | 可选；选择平台模型后，下方显示其最新版本的存储路径，供复制到启动命令 |
| 镜像 URL | 必填；推理运行环境 |
| 启动命令 | 可选；负责加载模型并启动服务进程 |
| 队列 | 必填；决定使用的计算容量 |
| 规格 ID | 必填；手工填写平台管理员确认的规格 ID |
| 可用区 | 必填，必须属于所选队列上报的分区；队列未提供可用区时手动填写 |
| 副本数 | 1 至 16 |
| 优先级 | 可选，1 至 9 |
| 仅校验 | 打开后只校验参数，不新建任何资源 |

必填项缺失或可用区不属于所选队列时，向导底部会显示原因，提交按钮不可用。队列列表或平台模型列表读取失败时，向导内会显示错误并提供「重试」。

::: tip 参考模型路径不会关联模型
「参考模型路径」只显示路径，不会把模型提交给部署，也不会自动挂载、复制或校验文件。启动命令中必须写明正确路径，并确认目标环境有读取权限。
:::

### 仅校验

- 选择已有服务时：校验部署参数，不新建部署。
- 选择新建服务时：只校验服务参数，不新建服务，也不校验部署参数。
- 仅校验不预留库存，正式提交仍可能因容量、配额或权限失败。

### 部署失败后重试

如果新建服务成功、但部署失败，向导会保持打开并保留填写内容，同时自动切换为「已有服务」并选中刚新建的服务。修正参数后再次提交只会新建部署，不会重复新建服务。

## 启动、停止和删除

| 对象 | 操作 | 影响 |
| --- | --- | --- |
| 服务 | 启动 | 重新占用队列资源，可能产生费用 |
| 服务 | 停止 | 副本释放，停止计费；影响该服务的全部流量 |
| 服务 | 删除 | 调用方将无法再访问该流量入口，无法恢复 |
| 部署 | 启动 / 停止 | 只影响该部署的副本 |
| 部署 | 删除 | 删除该部署配置，无法恢复 |

- 启动只对已停止的对象显示，停止只对服务中的对象显示；状态变化中的对象不显示操作。
- 每个操作都会二次确认；等待确认期间，该行按钮不可用，悬停可看到原因。
- 提交后页面提示「已提交…，正在确认」，该行按钮保持不可用，页面每 3 秒刷新一次，直到看到状态变化（最长约 2 分钟）。云端仍在受理时不会显示为失败，也不要重复提交。
- 列表或详情中有状态变化中的对象时，页面每 5 秒自动刷新；页面隐藏时暂停。
- 部署的启停会同时刷新服务列表，因为服务状态可能随之变化。

## 风险提示

- 多副本部署会持续消耗 GPU 和费用，不再需要时请停止或删除。
- 停止服务会影响全部流量；删除服务或部署无法恢复。
- 服务名称、描述、启动命令和截图中不要包含凭据或内部网络信息。

## 常见问题

### 为什么只能看到一个资源区？

页面只列出支持推理的资源区。只有一个资源区支持时，不显示切换。

### 提交后很久仍显示「正在确认」？

云端处理可能较慢。等待自动刷新即可；超过约 2 分钟仍无变化时，页面会提示「仍在处理中，请稍后刷新查看」。之后可在详情抽屉点 **刷新** 核对状态，不要重复提交。

### 选择模型后为什么仍要填写命令和路径？

「参考模型路径」只展示路径，不会自动挂载或加载模型，启动命令必须明确使用正确路径。
