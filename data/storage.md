# 存储与文件

Zenith 会把已接入的对象存储和文件存储集中展示。你可以先在总览中判断容量是否充足，再由有权限的用户查看对象、目录、挂载点和存储单元明细。

## 资源区与存储隔离

资源区 1、2、3、4 分别对应四个独立的存储区域，资源区 5、6 也是独立区域。开发机、训练任务与所挂载的存储需要位于同一区域；相同路径名不代表文件互通。切换资源区后，请重新检查队列和存储选择。

项目分类和已有存储绑定由平台管理员设置。显示“已登记绑定；挂载尚待验证”的存储暂时不能用于新建挂载，已有机器的挂载不受登记操作影响。

## 使用信息

| 项目     | 说明                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------- |
| 适用角色 | 普通用户查看本人获授权的文件与存储；平台管理员和运维可查看存储容量和完整存储清单，平台管理员可执行受支持的管理操作 |
| 界面路径 | 普通用户：**工作台 → 我的存储**；平台管理员和运维：**存储管理 → 概览 / 文件存储 / 对象存储**                 |
| 前置条件 | 平台管理员已经接入相应资源区的存储能力；当前账号具备所需的查看权限；对应数据来源处于可用状态                   |

不同资源区提供的存储类型并不完全相同。页面上没有某个标签、按钮或字段时，应以当前界面显示为准，不要假定其他资源区的操作也一定可用。资源区5 的开发机云盘只能增大：本人开发机可提交扩容申请，平台管理员可直接扩容；资源区1–4 的云盘关机后不保留；资源区6 的开发机请把需要保留的数据放在个人存储或项目存储，云盘不能扩容。新建机器或替换旧机器时，按[新开发机与存储迁移](/data/storage-migration)操作。

普通用户请优先使用 **工作台 → 我的存储**。那里只出现平台已经授权的个人存储、项目存储、挂载盘和绑定的存储桶，不能自己填写桶名。

## 共享存储桶与用户目录权限

平台管理员可以在 **存储管理 → 对象存储** 中将同一个存储桶绑定到多个项目，也可以在项目的桶授权区域逐个绑定。
每个项目独立设置整桶或指定目录、只读或读写权限；共享目录中的文件对所有获授权项目可见。
解除一个项目的绑定不会删除文件，也不影响其他项目。公共存储桶与项目存储桶的目录仍须互不重叠。

在 **存储管理 → 授权** 中，平台管理员还可以选择用户、平台管理的资源区5 或资源区10 存储桶、
桶内目录（如 `datasets/team-a/`）以及只读或读写权限。一个用户可以拥有多个目录，同一目录也可授权给多位用户。
目录名称区分大小写，不支持空目录、上级路径或整桶授权。用户可在 **我的存储 → 文件** 的“授权目录”分组中浏览、下载，
具备平台操作权限和目录读写权限时还可上传、新建目录及删除文件。

这些权限会叠加。新增只读目录授权不会收回该用户从项目或公共存储桶获得的更大权限；若只允许访问该目录，
应先移除其他更宽泛的授权。全局只读用户仍不能写入。目录授权不能签发整桶临时凭据，默认也不会挂载到开发机或训练任务。
如确需原生挂载，平台管理员还须在 **存储管理 → 对象存储** 中为对应存储桶开启 **用户目录挂载**；只需对少数共享桶开启。
撤销授权或关闭该开关会阻止新访问，但已签发的短期下载/上传链接或临时凭据仍可使用至原定到期时间。

## 新建时直接挂载存储桶

新建开发机或训练任务时，在“对象存储桶”中勾选已有授权，可同时选多个。
项目桶仍须先选择对应所属项目；标记为“个人目录”的独立授权不要求项目，但所属桶必须已开启用户目录挂载。
支持资源区5 和资源区10 的存储桶；桶只能用于所在资源区，并且必须位于该资源区的北京地域；无权访问、跨地域或其他资源区的组合会被拒绝。

一次创建只能选择同一资源区的桶。

平台管理员和运维在 **训练任务管理** 中 **按厂商参数新建** 资源区10 的训练任务时，在“存储挂载”中新增一项，类型选择 **BOS**（存储桶），再选择桶名、填写子目录和任务内挂载路径，并设置只读或读写；文件存储对应 **PFS**。普通用户仍通过上面的授权入口选择。

文件直接读写原桶，不会另建存储或复制数据。已有挂载继续使用原路径。新建项目桶挂载目录显示在选择框下方，为 `/projects/项目标识/buckets/桶名`（没有项目标识时使用项目 ID）；“个人目录”授权默认挂载到 `/mnt/buckets/授权ID`。
只读授权只能读取；读写授权可以写入；若绑定了桶内目录，只挂载该目录。已有开发机不会自动改挂。
对象挂载有缓存和文件操作语义限制，请避免多个进程同时改写同一文件；训练临时文件仍建议放在个人存储或项目存储。

OpenAPI 3.8.0：用具备 `storage:read` 的个人 Token 查询 `GET /pt/api2/me/bucket-mounts`，
在开发机或训练任务创建请求中传入 `bucket_mount_ids: ["返回的授权ID"]`。项目桶还必须传入匹配的 `project_id`，“个人目录”授权不受项目限制。
不接受自填桶名、源目录或访问密钥。可在下述挂载点设置中修改实例内的访问位置。按操作回执等待创建结束，再检查实际挂载。

## 新建时自定义挂载点

新建开发机或自定义训练任务时，选择资源区和需要挂载的存储后，可以在 **自定义挂载点** 中逐项填写实例内路径。例如，将个人存储从 `/personal_fast_storage` 改为 `/workspace/personal`，将某个项目授权子目录改为 `/workspace/input`。

此处支持已选择的个人存储、公共存储、容量数据层、项目存储、个人授权目录、数据集及项目存储桶。留空使用页面显示的默认路径。项目存储的根路径偏好仍有效；自定义挂载点可以进一步单独修改各授权子目录的位置。

- 修改的是新开发机或任务容器内的挂载位置，原文件和授权范围不变，数据集仍然只读。
- 路径必须以 `/` 开头，使用英文字母、数字、`.`、`_`、`-` 和目录分隔符；不能包含 `.`、`..` 路径段，或覆盖系统和平台保留目录。
- 多个挂载点不能相同，也不能互相包含，例如不能同时使用 `/workspace` 和 `/workspace/input`。
- 资源区5、资源区6 和资源区10 可以设置；资源区1–4 当前使用固定的已登记挂载路径。
- 此功能直接改变挂载位置，不会创建软链接或自动保留旧路径。启动命令应使用设置后的路径。
- 只影响本次创建，已有开发机和任务不变。复制任务会保留设置，提交前仍需核对当前存储授权和资源区。

如果切换资源区、项目或取消选择存储，请重新核对路径设置。页面会提示无效、冲突或已不在本次挂载范围内的配置。

## 浏览我的项目存储与存储桶

平台管理员可在 **项目 → 点击项目名称 → 存储** 的“已绑定存储”中，选择资源区5 或资源区10 的已有存储桶。
列表包含尚未纳入平台管理的桶；保存时会先登记，再绑定到当前项目。可授权整个桶或指定目录前缀，并选择读写或只读。
整桶授权会让项目成员访问桶内已有文件；不同项目和公共授权的目录前缀不能重叠。
已绑定此项目或已停用的桶不能重复选择；已停用的项目存储需要勾选启用后才可绑定。
绑定成功后本页自动刷新。普通项目成员需要联系平台管理员绑定其他桶。

1. 打开 **工作台 → 我的存储 → 文件**。左侧“存储位置”按“个人存储”“项目存储”“公共存储”“授权目录”“存储桶”分组，只列出当前账号已获授权的资源；手机上是一个可搜索的下拉框。
2. 在存储位置上方搜索存储名称、项目名、桶名或资源区，点击一项即可在右侧浏览。所选位置会写入地址栏的 `source` 参数，刷新或分享链接后仍会打开同一位置。
3. 右侧依次是路径、搜索当前目录、新建目录、上传和更多。**刷新** 只重新加载当前目录，不会回到根目录。上传同名文件、删除文件或目录前都会先确认。
4. 也可以从 **项目 → 点击项目名称 → 存储** 直接进入当前项目的文件存储和存储桶。
5. 浏览存储桶时，点击 **更多 → 签发临时凭据**，核对桶和有效期后签发。可用于 SDK 上传、分片上传和下载，最长 12 小时；不包含删除对象或管理桶的权限。

只有具有平台操作权限、且被授予资源区5 或资源区10 存储桶**整桶读写权限**的账号可以签发这类临时凭据。
项目角色为只读的成员、仅授权指定目录或尚不支持临时凭据的存储会在菜单项后显示原因；仅有目录权限时，继续使用网页文件浏览器。
未获授权的桶请联系平台管理员绑定，不支持自行填写桶名来扩大权限。
临时密钥仅在当前弹窗显示，关闭、切换存储或到期后清除；不要分享给其他用户。

项目成员身份不代表能浏览其他成员的个人存储。不同资源区的同名目录仍是不同存储；
文件存储在浏览前需要先连接：页面显示“已连接”及访问方式后才会列出目录。

## 个人、项目和对象存储分别是什么

| 存储面               | 用户怎么用                                                                           | 计费与形态                                                                                                                       |
| -------------------- | ------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 个人存储             | 新建时勾选后挂到 `/personal_fast_storage`；也可在 **我的存储 → 文件** 浏览            | 从共享文件存储中划出的独立空间，不是存储桶。属于包内资源，新开不产生额外现金费用                                                 |
| 项目存储             | 开关开启时，成员自动获得本人的学号/工号目录和项目 `public` 目录                      | 新旧绑定都按现有开关生效；其他目录或整个根目录由项目的负责人或管理员另行授权                                                     |
| 挂载盘               | 平台管理员把已有的云端存储卷分配给你或项目；新建时可勾选，资源区6 的开发机可重启后追加 | 登记/删除只改平台记账，不会创建或删除云上的卷                                                                                    |
| 对象存储             | 只显示平台管理员绑定到项目或公共范围的桶前缀                                         | 资源区5 存储桶的费用尚未确认时应视为计费未知。网页操作使用受限接口或短时地址；有整桶读写授权时可单独签发临时凭据                 |

资源区6 的高性能和容量型文件存储都在包月套餐内。资源区1–4 目前不能由平台自动挂载个人存储和项目存储。其他资源区不要假定可以从本平台购买存储桶或文件存储。

网页浏览文件存储需要平台服务或本人一台运行中、已挂载该存储的开发机来连接；浏览存储桶不需要。连接不上时，页面会给出原因和“重新连接”按钮。

## 区分同名挂载点与真实存储来源

在 **我的存储 → 用量**，个人存储和公共存储按资源区各显示一张卡片，卡片大小相同，只显示已用、额度和更新时间。
不同资源区都可以挂到 `/public_fast_storage`；这是各自开发机内的访问位置，不代表同一份数据，也不会自动同步。
公共存储卡片上的 **浏览文件** 会切到“文件”并打开对应资源区的公共存储。公共存储与项目存储、个人存储的额度分别计算。
页面顶部的指标行显示各资源区个人存储的已用量；超额时只显示一条提醒，点击 **清理文件** 会打开对应的个人存储。

页面保留实际用量，进度条最多显示 100%。额度可能被实际用量超过，此时卡片会显示超出的数量；
这不等于底层文件系统已经写满，也不要把超额数值直接当成数据损坏。没有单独配置额度时，卡片显示“未设额度”，
不会把共享文件系统的总容量当成该目录的额度。
未知用量显示为“—”，不表示空目录；最近统计失败时，卡片保留上次用量并提示统计失败。

个人用量的 **立即检测** 需要你在卡片所示资源区有一台运行中、已挂载个人存储的开发机，或平台统计服务可用；
条件不满足时按钮不可用，并在按钮旁说明原因。其他资源区的机器或只创建同名本地目录都不算。
在“文件”中删除个人文件后，用量要等下一次统计才会更新，页面会提示你到“用量”点 **立即检测**。

## 查看开发机挂载与挂载盘

**我的存储 → 挂载** 有两张表：

- **开发机挂载**：每台开发机一行（不含已释放和回收站中的机器），展开后查看每个挂载的路径和“读写/只读”。可按开发机名称或挂载路径搜索全部记录。
- **我的挂载盘**：分配给你的挂载盘。行操作 **挂载到开发机** 只列出同资源区、属于你的开发机，选择后打开与“我的开发机 → 更多 → 调整存储挂载”相同的窗口。

两张表的 **刷新** 会同时更新两张表；读取失败时显示错误和“重试”，不会显示为空列表。

## 在总览中查看存储用量

1. 平台管理员或运维打开 **存储管理 → 概览**。
2. 在页面顶部按资源区筛选，查看平台管理存储单元的数量和已用合计。
3. 在“用途分布”中查看个人存储、项目存储、公共存储、混合用途及其他（待分类）。
4. 点击“平台管理存储单元”进入 **文件存储**，逐条核对容量配额和实际已用量。
5. 点击页面右上角的 **刷新** 重新加载数据。

仅监控只包含平台管理的文件系统内未使用的存储单元，不等于整个云账号。分类来自配置用途，不代表访问授权；共享单元只计一次，无法分类或读取的项会明确标注。无上限的存储单元显示“不限”，未知用量不会当成零。

对象存储通常只显示桶的数量或区域分布，不显示总容量和已用容量。这是正常现象，不能据此判断对象存储中没有数据。

## 浏览对象存储

详细对象清单仅对平台管理员和运维开放。

1. 进入 **存储管理 → 对象存储**，选择资源区。
2. 打开“对象存储”标签。
3. 在桶列表中按名称或区域搜索，并点击桶名称进入。
4. 使用面包屑进入或返回目录前缀。
5. 如列表没有完全展开，点击“加载更多”。
6. 需要向他人提供临时下载入口时，选择对象或目录并点击“分享”。详细说明见[文件分享](/data/file-shares)。

普通用户只能处理平台管理员为本人授权的目录。若提示目录不在个人范围内，请不要反复重试，改为选择自己的目录或联系平台管理员确认。

## 查看文件存储

1. 进入 **存储管理 → 文件存储**。
2. 选择资源区，查看文件系统的状态、容量、带宽、区域和挂载点。
3. 查看文件系统中的存储单元。
4. 核对存储单元的路径、容量配额和文件数配额。
5. 若界面提供 **新建 Fileset**，填写路径和可选名称后提交；按钮不可用表示当前资源区或账号不支持从 Zenith 新建。

页面右上角的 **刷新** 会更新当前标签页的文件系统和存储单元列表。
列表中存在创建中、更新中或删除中的条目时，页面可见且资源区连接正常期间约每 5 秒查询一次状态，状态稳定后停止自动查询。
切到其他浏览器标签页会暂停查询，返回时继续检查尚未完成的条目。

::: tip 挂载点的作用
挂载点是计算环境访问共享数据时需要使用的路径。发起文件迁移前，还要确认同一路径对迁移服务可访问；仅在计算实例中看到一个路径，并不代表迁移服务一定能访问它。
:::

## 项目存储的目录授权

项目存储与直接授予个人的目录授权分开管理。平台管理员把已有的文件存储绑定到一个或多个项目；
每个绑定各自保存成员权限和挂载路径偏好，同时共用原有数据和容量。对应开关开启时，成员自动获得本人
经过核验的学号/工号目录和项目 `public` 目录。项目的负责人或管理员在 **项目 → 点击项目名称 → 存储** 中管理这些开关和额外授权：
选择 **整个绑定范围** 或 **指定子目录**，再选择只读或读写。其他成员的目录和整个根目录都需要额外授权，项目的管理员本人也不例外。
整个绑定范围的授权会在原挂载根目录下开放绑定根目录及其全部下级目录。
也可以给一位成员授权多个目录，例如 `yining` 和 `datasets/research-a`；每个挂载只开放被授权的路径。
同一成员在同一存储上不能同时使用整个绑定范围和子目录授权。容量仍共用原存储的配额。

新旧项目绑定使用同样的学号/工号目录和 `public` 开关。没有经过核验的学号/工号时，只能使用 `public`。
项目角色为只读的成员始终只读。撤销额外授权不会移除自动获得的访问；关闭默认开关也不会移除对同一目录
或整个根目录的单独授权。要以只读方式授权整个存储，请先关闭可写的默认目录；整个存储的读写授权会覆盖这些目录。
已运行的挂载需要明确更新；保存授权不会移动或删除文件。直接授予个人的授权（包括共享存储上的独立研究人员条目）
继续按原有流程使用。

## 开放已有存储单元的挂载权限

平台管理员可以在 **存储管理 → 文件存储** 中选择资源区5，找到平台管理的存储单元，
点击该行的 **授权**，开放整个存储单元或其中已有的指定子目录。直接授权给个人无需加入项目；
已绑定给一个或多个项目的存储单元也可以直接授权给个人，整个存储单元与各子目录的授权分别保存。

完整的图文操作请阅读 **[Fileset 共享与个人授权](/data/fileset-access)**：

- [平台管理员：将同一存储绑定给多个项目](/data/fileset-access#shared-project-bindings)。
- [平台管理员：填写相对路径、读取目录授权、添加用户并保存](/data/fileset-access#admin-grant)。
- [用户：在开发机或训练任务的“个人授权目录（可多选）”中选择挂载](/data/fileset-access#user-mount)。
- [修改范围、撤销授权与运行中挂载的边界](/data/fileset-access#scope-and-revoke)。
- [已保存但创建时报 AccessDenied 的排查方法](/data/fileset-access#access-denied)。

授权不创建目录、不搬移文件、不增加子目录配额，也不自动修改资源区5 云端的权限。
请先确认目录存在，Zenith 调用身份及目标计算队列已具备完整源路径的权限。
保存成功不代表云端挂载已验证；撤销授权也不会自动卸载已有机器上的目录。

## 如何判断数据已更新

- 刷新完成后，加载状态消失，容量、状态或对象列表重新显示。
- **新建 Fileset** 的提交成功提示只表示请求已受理；列表中创建中的条目会自动更新，也可点击刷新，直到新条目出现并进入可用状态。
- 对象或文件系统刚创建、扩容后，页面数据可能短暂滞后。等待片刻后再刷新，避免连续重复提交。
- 若页面明确显示某个数据来源不可用，当前数值可能不是最新结果。

## 风险提示

::: warning 存储费用是估算值
“≈ 金额/天”按已用容量和平台配置的静态单价计算，只用于趋势判断，不是云厂商账单或最终结算依据。未显示金额不代表存储免费。
:::

- 对象存储没有统一的桶容量统计，桶数量不能代表数据量。
- 挂载点、区域和访问权限必须与实际计算任务匹配；能看到文件系统不等于已经挂载到实例。
- 清理未完成的分片上传可能释放占用，但也会使对应上传无法继续；确认对象名称后再操作。
- 新建存储单元可能受容量、权限或资源区限制影响，提交前先确认命名和路径。

## 常见问题

### 为什么我看不到“存储管理”或桶名称？

详细资源清单只对平台管理员和运维开放。普通用户请打开 **工作台 → 我的存储**，只浏览平台已经授权的个人存储、项目存储、挂载盘和绑定的存储桶；不要自行填写桶名。

### 容量显示为“—”或只有总量，没有已用量

当前资源区可能没有返回该项数据，或尚未完成用量采集。请以页面明确展示的字段为准，不要把“—”理解为零使用量。

### 新建 A100 / H100 开发机提示个人存储标识不安全？

个人存储的目录名来自账号的**存储标识**（`personal_namespace`），不是登录名。钉钉账号的登录名有 73 个字符，不能直接当作路径。平台会为每个账号分配一个不冲突的短目录名；可在 **账号设置 → 个人资料** 或平台管理员的 **用户管理** 列表中查看。资源区1–4 的 5090 规格当前不自动挂载个人存储，所以不会出现这条检查。

升级前如果曾用大小写混合的登录名，通过共享父挂载在 `/personal_fast_storage/Alice` 一类路径写下过文件，升级后探针会改看新的个人存储目录。需要保留旧数据时，请联系平台管理员做一次明确迁移，平台不会自动改名。

### 文件系统存在，为什么计算任务仍找不到目录？

文件系统存在并不等于已经挂载到当前实例。请核对实例创建配置、挂载路径、区域和访问权限；不确定时联系项目管理员。

开发机页面的挂载配置来自资源区上报，不代表机内目录已经可用。打开终端后，可用
`df -h /personal_fast_storage` 查看该目录实际所在的文件系统；其他目录替换为对应路径。
如果结果指向容器根目录或 `overlay`，先停止向该目录写入重要文件，并联系平台管理员检查挂载。
`df -h` 的总表可能省略重复挂载，同一共享文件系统的多个目录应分别检查，或使用 `df -ah`。
参见 [GNU df 说明](https://www.gnu.org/software/coreutils/manual/html_node/df-invocation.html)。

“我的存储 → 文件”可以经平台服务访问自己的目录；未启用平台服务时，要求本人有运行中的开发机、终端可连接，并能验证真实存储挂载。
如果提示需要一台运行中的开发机，请逐项确认后点 **重新连接**。跨资源区的个人和项目文件互不自动同步；
需要迁移时使用下方迁移指引。旧机器本地目录中的文件也不会因修复挂载而自动移入共享存储，
请先备份并由平台管理员确认迁移方式。

### 如何把文件交给他人或迁到另一环境？

- 临时提供下载地址：阅读[文件分享](/data/file-shares)。
- 在已支持的环境之间复制文件或目录：阅读[文件迁移](/data/file-migrations)。
- 从旧开发机迁到新开发机：阅读[新开发机与存储迁移](/data/storage-migration)。

## 已有开发机调整公共存储

资源区5 的开发机先停止，再从「我的开发机 → 更多 → 调整存储挂载」选择保持现状、补挂公共存储或取消公共挂载。保存后仍为停止状态，下一次启动时生效。取消挂载不会删除公共文件，个人盘、项目盘及其他挂载保持不变。

已有开发机的附加挂载以调整窗口提供的候选为准：普通用户可在本人开发机上选择符合权限和资源区要求的个人授权目录、项目分配盘或数据集。直接授权的整个存储单元或子目录无需加入项目；项目存储仍按成员权限挂载。资源区5 调整需先停机，资源区6 需确认重启；路径与读写权限由平台检查。授权失效但仍挂载的目录会提示卸载，移除挂载不会删除云端文件。公共存储容量由平台管理员在存储配额中调整，与是否挂载分开管理。

## 存储桶临时凭据

需要使用原生 SDK 或上传工具时，平台管理员可在 **存储管理 → 对象存储** 中选择平台管理的资源区5 存储桶，
点击 **签发临时凭据**。成员在 **我的存储 → 文件**（或项目详情的 **存储** 标签页）中打开存储桶，对具有整桶读写权限的
存储位置选择 **更多 → 签发临时凭据**。每位成员的每次签发都使用独立的临时会话；项目角色为只读的成员不能签发临时凭据。
仅有目录授权或只读授权时，不能签发整桶凭据。

有效期可选 15 分钟、1 小时、6 小时或 12 小时（默认上限），签发后复制 JSON。
在 SDK 中配置存储桶、地域、访问域名、访问密钥 ID、访问密钥**以及会话令牌**。到期后回到 Zenith 重新签发，不会自动续期。

这些凭据可以列出、读取、上传、覆盖和分片上传，不能删除文件，也不能管理 ACL 或存储桶。只分享给获得授权的接收人。
关闭弹窗会清除弹窗中的副本，但不会撤销已经复制到别处的凭据；修改来源授权会阻止之后的签发，
已有的云端会话仍可能在到期前继续可用。如果弹窗提示缺少云端角色，需要云账号管理员先完成 IAM 配置，才能签发凭据。

## 项目对象存储的成员目录权限

项目的负责人、管理员和平台管理员可在「项目 → 点击项目名称 → 存储 → 成员权限」中为成员设置访问范围。
新绑定的「限制到个人目录 + 公共目录」默认关闭，成员可访问项目已绑定的整个桶范围；绑定了前缀时仍只能访问该前缀。

1. 选择项目桶和成员。
2. 开启限制并保存后，只授权该成员的学号 / 工号目录和 `public`，不再附带整桶权限。已有只读权限会保留，不会创建云端目录。
3. 关闭并保存后，该成员恢复访问整个绑定范围；其他成员和 Fileset 设置不受影响。

此前开启过个人目录的选择会保留勾选。若显示“待应用”，保存时需要通过工作负载检查；不能把勾选状态当成限制已生效。
收窄权限前需停止相关开发机和任务，并等待未完成操作结束；已有开发机的实际挂载需要另外调整。
成员缺少有效学号 / 工号时不能开启限制。原先独立配置的精确目录授权继续保留，不会因页面加载而放开访问。

这些授权也用于「我的存储 → 文件」、个人 API 和同区项目桶挂载。目录权限不能签发整桶临时凭据；只有
明确获得整个桶读写权限且满足角色要求才可以。成员只能获得项目桶权限上限以内的访问，
项目角色为只读的成员始终只读。独立用户授权、公共存储桶和其他项目的权限会叠加，不能通过这里的只读设置
收窄其他来源的读写权限。移除成员后再加入不会恢复旧目录授权。已有链接和临时凭据仍有效至到期。
