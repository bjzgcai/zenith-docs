# 共享数据集

在侧栏「数据集」中查看全平台已发布的数据集，这是唯一入口。每个资源区的数据独立，
可搜索名称、描述或 ID，并按资源区筛选；卡片显示挂载位置、发布状态和当前账号能否维护，每页 12 张。

## 浏览、下载与使用

点击「浏览文件」在右侧抽屉中查看目录或下载文件。新建开发机或训练任务时，在独立的「数据集（可多选，只读）」
选项中选择数据集。「个人授权目录」也可多选，两组选择分别保留，清空一组不会清空另一组。
所有选中的目录和数据集必须位于同一资源区；数据集的独立子目录以只读方式挂载。
即使你是平台管理员或数据集维护者，计算环境中也不能写入数据集。请将处理结果写入个人存储或项目存储。

现有开发机可以在存储挂载配置中追加已发布的数据集；是否需要停机由对应资源区能力决定。
选择“不挂个人和项目存储”模式时不能额外选择数据集。

## 维护文件

平台管理员和指定的数据集维护者在「浏览文件」中还可以上传、建目录、
重命名和删除文件；删除前会提示所有挂载该数据集的开发机都将看不到被删除的内容。普通用户没有这些操作权限。计算机器只读规则不会随维护权限改变。
上传、下载沿用平台文件服务的单文件限制，默认 8 MiB；大型模型等文件请使用只读挂载读取，
大型导入由平台管理员安排受保护的存储导入流程。

## 管理与发布

平台管理员在平台管理员视图的「数据集」页点击「登记数据集」，登记共享数据集存储下的独立子目录并指定维护者；
卡片上的「设置」用于修改名称、维护者和发布状态，页面还提供状态筛选（地址栏 `status` 参数）。旧的「数据集管理」地址会跳转到这里。
同一文件存储上的数据集共用一个共享数据集存储。建议先保存为未发布状态，平台会准备独立的上传目录，完成导入后再发布。
若提示目录未就绪，设置仍已保存，请检查登记时选择的开发机（它负责准备上传目录）后重新保存；登记成功后即使后续设置失败，列表也会立即显示新数据集，再次保存会更新它而不会重复登记。
打开或关闭「发布到全平台」后保存时，页面会先请你确认。
发布前平台会检查存储和可写挂载；检查未通过会显示原因，普通用户暂不可选。
资源区5 的发布检查覆盖 Zenith 已登记的全部队列（包含停用队列）。其他团队不由平台管理的云资源，以及云账号管理员的直接操作，不属于平台控制范围。
未发布的数据集仅对平台管理员和维护者可见。

停用后会隐藏数据集并阻止新挂载和启动；已经运行的只读挂载仍会保留。
**存储管理 → 挂载盘** 中的数据集会跳转至「数据集」页，不能作为普通可写盘分配。

## OpenAPI

在个人 API Token 中选择「共享数据集目录与文件读取」（`datasets:read`）。
需要维护文件时还需「数据集文件维护」（`datasets:write`），且账号必须仍是该数据集的
维护者或平台管理员。已有 Token 不会自动新增权限，请按需创建新 Token。

| 操作 | 接口 |
| --- | --- |
| 列出数据集 | `GET /pt/api2/ai/datasets` |
| 详情与挂载信息 | `GET /pt/api2/ai/datasets/{id}` |
| 列目录 | `GET /pt/api2/ai/datasets/{id}/files?path=子目录` |
| 读取文件 | `GET /pt/api2/ai/datasets/{id}/file?path=文件名` |
| 上传 | `POST /pt/api2/ai/datasets/{id}/file` |
| 建目录 / 重命名 / 删除 | `POST /pt/api2/ai/datasets/{id}/{mkdir,rename,delete}` |

所有路径均相对于该数据集目录。上传使用 JSON `path`、`content_base64` 和可选 `overwrite`；
下载返回 `content_base64`，上限见详情的 `max_transfer_bytes`。目录列表最多返回 2000 项，
`truncated=true` 表示未完整列出。文件写入没有幂等回执，网络超时后请先查询文件确认结果。

新建开发机或训练任务时传入 `mount_disk_ids: ["数据集 ID"]` 即可只读挂载，
仍需相应的创建权限、资源额度和匹配的资源区。
卡片中的「挂载说明」只显示创建请求需要加入的挂载参数（`resource_zone` 与 `mount_disk_ids`），可一键复制，并链接到本文档。
完整请求结构见 [个人 API](../reference/personal-api)。个人 Token 不能登记、发布数据集或配置维护者。


## 资源区与现有机器的目录

数据集发布后全平台可查询，但文件只存在于卡片标明的资源区。其他资源区需要单独导入并登记，
平台不会自动复制。OpenAPI 可使用 `GET /pt/api2/ai/datasets?resource_zone=10` 筛选本区数据。

卡片中的目录是创建时的计划挂载位置。已有开发机请通过其 `mounts_url` 查询云端实例实际配置的
容器内目标目录；返回值会注明清单是否完整、是否在容器内核验，不能用存储后端路径替代。
