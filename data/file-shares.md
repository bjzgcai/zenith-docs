# 文件分享

文件分享用于为对象存储中的文件或目录生成限时下载链接。收到链接的人无需登录 Zenith，因此分享前必须确认内容、接收人和有效期。

## 使用信息

| 项目 | 说明 |
| --- | --- |
| 适用角色 | 平台管理员；普通用户和项目管理员看不到该入口 |
| 界面路径 | 创建入口：**存储管理 → 对象存储 → 存储桶 → 浏览 → 分享**；记录入口：**存储管理 → 对象存储 → 分享记录** |
| 前置条件 | 使用平台管理员账号；文件位于当前环境支持分享的对象存储中；目标对象仍然存在且可读取 |

「我的存储」可浏览已授权的项目桶和公共存储桶并上传或下载，但暂不提供「分享」按钮。普通用户需要分享时，请联系平台管理员使用组织认可的交付方式。

## 创建分享链接

1. 在 **存储管理 → 对象存储 → 存储桶** 中点击目标桶的 **浏览**，进入目标文件所在目录。
2. 确认选中的是正确的文件或目录，然后点击“分享”。
3. 选择链接有效期：30 分钟、1 小时、6 小时或 24 小时。
4. 可填写备注，例如接收人或用途。备注不会成为访问密码。
5. 点击“生成分享链接”。
6. 复制生成的链接，并通过可信渠道发送给接收人。
7. 点击“完成”关闭窗口。

::: tip 优先选择较短有效期
分享链接本身就是访问凭据。只要满足使用场景，应优先选择 30 分钟或 1 小时，并避免发送到公开群聊、公开文档或工单截图中。
:::

## 分享目录时会发生什么

目录分享会为当前列出的对象分别生成下载链接，最多处理前 50 个对象。它不是一个可以持续浏览整个目录的永久入口。

创建前请注意：

- 超过 50 个对象时，不能认为整个目录已经完整分享。
- 分享创建后新增到目录中的文件不会自动加入已有分享。
- 接收人获得的是各文件的下载链接，不会获得 Zenith 账号或项目权限。

## 查看和重新获取链接

1. 打开 **存储管理 → 对象存储 → 分享记录**。
2. 查看对象路径、类型、资源区、状态、过期时间和备注。
3. 对仍处于“有效”状态的记录点击“获取链接”。
4. 系统会按剩余有效期重新生成可用链接。
5. 点击“复制”后，再次通过可信渠道发送。

分享记录列出所有用户的分享（最近 1000 条），「分享人」列显示创建者，可按桶、对象、备注或分享人搜索。

## 删除分享记录

1. 在 **分享记录** 中找到目标记录。
2. 点击「删除记录」。
3. 阅读确认框，核对对象和过期时间。
4. 确认删除后，该记录从列表中消失。

::: danger 删除记录不会让已生成的 URL 立即失效
删除只会去掉 Zenith 中的分享记录。已经复制或发送出去的分享 URL 会继续有效，直到它各自的过期时刻。若内容敏感，请同时移动、重命名或删除原对象，并联系平台管理员评估后续处理。
:::

## 如何判断分享成功

- 页面提示“分享链接已生成”。
- 弹窗中出现一个或多个对象名称和对应链接。
- **分享记录** 中出现新的有效记录，并显示预期的过期时间。
- 接收人可在有效期内下载目标文件。

如果只看到部分目录文件，请返回对象列表确认当前加载范围，并检查是否超过 50 个对象。

## 风险提示

- 分享链接不要求登录，任何获得链接的人都可能下载内容。
- 备注不是密码，也不会限制接收人。
- 不要分享包含口令、Token、私钥、个人信息或受限数据的文件。
- 链接过期时间以创建时选择的时长为准；重新获取链接不会延长原分享记录的总有效期。
- 分享能力只在部分对象存储环境中提供。按钮不存在或提示不支持时，请联系平台管理员选择其他安全交付方式。

## 常见问题

### 为什么“分享”按钮不可用？

可能原因包括：当前账号不是平台管理员、存储类型不支持分享、目标已被删除，或当前数据来源暂不可用。请先刷新对象列表并核对路径。

### 为什么无法获取旧链接？

分享记录已经过期或被删除时，不能再从记录页获取链接。需要继续分享时，请从原文件重新创建一条分享记录。

### 我删除记录后，对方为什么仍能下载？

这是预期行为：对方使用的是此前已经生成的限时 URL，它会持续有效到原过期时间。敏感场景应选择短有效期，并在误分享时立即处理原对象。

### 在哪里确认原文件？

返回[存储与文件](/data/storage)中说明的对象存储入口，根据分享记录中的路径逐级核对。
