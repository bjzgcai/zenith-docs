# Fileset 共享与个人授权

平台管理员可以把同一 Fileset 绑定给多个项目。对于资源区5（火山）的 Fileset，还可以独立把**整个 Fileset** 或其中的**已有子目录**（subdirectory）授权给指定用户，即使该 Fileset 已绑定给一个或多个项目。用户无需加入这些项目，即可在创建开发机或训练任务时选择挂载授权范围。

各项目的成员目录权限、用户的整盘授权和子目录授权分别管理。它们访问原来的同一份数据，共用 Fileset 容量；相同源目录中的修改会被其他有权访问该目录的人看到。

本例把 `research-data` 中的 `/research/users/alice` 授权给 Alice。此次授权只包含该目录及其内容，不额外开放 `/research` 或其他用户目录。

已经获得授权的用户可直接阅读[用户如何选择挂载](#user-mount)。

## 将同一 Fileset 绑定给多个项目 {#shared-project-bindings}

1. 平台管理员打开第一个项目的 **项目详情 › 存储 › 已绑定存储**，点击 **绑定存储**。
2. 选择平台管理的文件系统和目标 Fileset，例如 `project-battery`，点击 **绑定到此项目**。
3. 打开第二个项目，重复上述操作并选择同一个 Fileset。原有项目绑定仍保留，不会转移数据或创建第二份 Fileset。
4. 项目的负责人或管理员在各项目的 **项目详情 › 存储 › 成员权限** 中分别核对成员目录权限。绑定本身不向所有成员开放整个 Fileset；成员仍按各自的目录授权访问，项目角色为只读的成员保持只读。

项目绑定记录和个人默认挂载路径分别保存。项目 Fileset 和项目桶都可以按绑定保存个人默认挂载目录；调整某个项目的成员目录授权或挂载路径不会修改另一个项目的设置，但授权指向相同源目录时，文件仍然共享。个人存储、公共存储和数据集等平台保留范围不能通过此操作改作共享项目存储。

需要额外授权某个用户访问本绑定目录时，可直接点击资源区5绑定行的 **授权**。此入口只编辑绑定的精确目录；选择整个 Fileset 或其他子目录，请使用下文的 **存储管理 → 文件存储** 入口。该编辑器管理额外的用户或项目授权，不会替换项目绑定和项目成员目录设置。

## 开始前确认

- 使用**平台管理员**账号，并切换到**平台管理员视图**。
- 目标文件系统已纳入平台管理，Fileset 和子目录都已存在；此操作不创建目录、不复制数据。
- 已确认目标用户的登录名，避免将同名用户选错。
- Zenith 使用的**云端调用身份和目标计算队列**已对完整源路径具备所需权限。某位用户自己的云账号有权限，不代表 Zenith 的调用身份也有权限。

::: warning 保存授权与实际挂载是两步
保存成功只表示 Zenith 已记录授权，不代表子目录实际存在、云端权限已就绪或计算环境已成功挂载。Zenith 不会通过此操作自动新增、修改或撤销云端授权；“读写”也不能突破云端权限。
:::

## 平台管理员如何授权 {#admin-grant}

### 1. 找到 Fileset

1. 打开左侧 **存储管理**，进入 **文件存储** 标签页。
2. 在页面顶部选择 **资源区5**，在搜索框中输入目标 Fileset，例如 `research-data`。
3. 点击该 Fileset 行的 **授权**，核对弹窗中的名称、Fileset 根目录和文件系统信息。
4. 授权保存后，也可以在 **存储管理 → 授权** 中按用户、项目或目录统一查看和撤销。

### 2. 填写并读取子目录

如需授权整个 Fileset，保持 **整个 Fileset**，核对根目录后直接继续[添加用户并保存](#add-subject)。该授权包含 Fileset 下的所有内容；需要限制到某个子目录时，使用以下步骤。

1. 选择 **指定子目录**。
2. 手动填写相对路径 `users/alice`。这里是文本输入框，不是目录浏览器。
3. 核对 **授权源路径** 为 `/research/users/alice`。
4. 点击 **读取此目录授权**，等待当前目录的授权列表加载，再编辑授权对象。

| 界面信息       | 本例内容                | 如何填写或核对                                   |
| -------------- | ----------------------- | ------------------------------------------------ |
| Fileset 根目录 | `/research`             | 由所选 Fileset 提供，不在相对路径中重复填写      |
| 相对子目录     | `users/alice`           | 手动填写，不以 `/` 开头或结尾                    |
| 授权源路径     | `/research/users/alice` | 平台组合后的完整源路径，保存前务必核对           |
| 开发机内路径   | 以弹窗或创建页显示为准  | 是开发机或训练容器内的访问位置，不等于云端源路径 |

相对路径不能包含空路径段、反斜线、单独的 `.` 或 `..`。例如 `/users/alice`、`users//alice`、`users/../alice` 都不是有效输入。

::: tip 修改目录后要再次读取
切换“整个 Fileset / 指定子目录”或修改相对路径，会丢弃尚未保存的授权草稿。请重新核对路径并读取授权；底部的 **刷新** 也会用已保存的列表替换当前草稿。
:::

[![指定子目录 users/alice，核对完整源路径后点击读取此目录授权](/images/fileset-access/read-scope.jpg)](/images/fileset-access/read-scope.jpg)

截图使用本地示例数据，可点击放大。
:::

### 3. 添加用户并保存 {#add-subject}

1. 点击 **添加用户或项目**，新增一行授权。
2. 保持类型为 **用户**，在用户下拉框中搜索并选择 **Alice（alice）**，同时核对显示名和登录名。
3. 新授权默认 **只读**。仅在需要写入数据或保存结果时改为 **读写**。
4. 保留当前目录中其他仍需使用的授权行，点击 **保存授权**。

同一用户在一个目录内只设置一条授权。需要授权多人时，继续添加用户行。本教程选择“用户”；仅添加“项目”授权，不会让目录出现在普通用户的“个人授权目录”候选中。

### 4. 重新打开核对

保存成功后弹窗关闭。再次从该 Fileset 的 **授权** 进入，选择相同子目录并读取授权，确认用户、访问权限和**开发机内路径**。

::: details 查看保存后再次读取的真实弹窗截图
[![保存后再次读取，显示 Alice 的读写授权及开发机内路径](/images/fileset-access/saved-grant.jpg)](/images/fileset-access/saved-grant.jpg)

截图只展示 Zenith 授权保存结果，不代表云端挂载验证结果。
:::

从 **存储管理 → 挂载盘 → 授权** 进入已登记的盘时，只能编辑该盘的精确目录。要授权另一个子目录，请回到 **文件存储** 中对应的 Fileset。若提示挂载盘已停用，还需在 **存储管理 → 挂载盘** 中启用后才能使用。

## 用户如何选择挂载 {#user-mount}

1. Alice 打开[新建开发机](/compute/workbench)或[新建训练任务](/workloads/training)，选择 **资源区5**。
2. 在开发机的 **存储与连接** 或训练任务的 **存储与数据集** 中，打开 **个人授权目录（可多选）**，选择平台管理员刚授权的目录。平台管理员视图中该字段显示为 **授权挂载目录（可多选）**。
3. 核对选项中的**实例内挂载路径和读写权限**。本教程的直接用户授权无需选择项目。
4. 提交创建，待资源运行后核对实际挂载。训练入口命令应使用页面显示的实例内路径；只读目录不能用于写入输出或检查点。

同时选择项目目录和个人授权，或选择整盘与子目录时，请核对各自的实例内路径不能相同或互相包含。历史授权可能保留原项目挂载路径；发生冲突时，可在创建页的[自定义挂载点](/data/storage#新建时自定义挂载点)中为各授权目录设置不同的位置，无需修改原存储数据或默认授权。

保存授权不会让已有机器自动挂上该目录。已有开发机需要追加此目录时，用户可以从本人开发机的 **更多 → 调整存储挂载** 选择同资源区的个人授权目录，已有项目绑定不会阻止该操作。资源区5需先停机，保存后保持停止，下一次启动生效。完整说明见[已有开发机调整公共存储与挂载盘](/data/storage#已有开发机调整公共存储)。

**我的存储 → 文件** 访问这类挂载盘，需要本人有已挂载该盘、运行中且终端可连接的开发机。目录出现在可选列表中，不等于已能通过文件浏览器访问。

## 授权范围与撤销 {#scope-and-revoke}

- **按目录分别管理。** `/research/users/alice` 与 `/research/users/bob` 可以分别授权；一次保存只更新当前目录的授权列表。
- **项目绑定、整盘与子目录授权可以并存。** 同一 Fileset 可以绑定多个项目，也可以同时登记 `/research` 和 `/research/users/alice` 等个人授权范围。每次保存只更新当前精确范围，不会复制父目录的授权到子目录，也不会改变其他项目的成员权限。
- **权限可能来自多个范围。** 整个 `/research` 的授权已经包含 `/research/users/alice`。删除 Alice 的子目录授权，不能收回她另行获得的整盘授权；若整盘只读、子目录读写，也应分别核对实际挂载路径与访问权限。
- **配额仍属于原 Fileset。** 子目录共用 Fileset 的容量配额，不会得到独立硬配额，也不会搬移或删除原文件。
- **数据集使用独立入口。** 共享数据集 Fileset 应在[数据集页面](/data/datasets)管理维护者和只读挂载，不通过此入口开放整个 Fileset。

撤销时，读取**同一个目录**的授权，在目标用户行点击 **移除**，再点击 **保存授权**。这会阻止该条授权带来的后续挂载和文件访问，但不会自动卸载已运行机器上的目录或停止任务。

如果用户仍通过其他项目、直接授权，或弹窗中提示的挂载盘分配（“已分配给…”）获得权限，仍可能访问。该分配需在 **存储管理 → 挂载盘** 中单独调整；需要收回运行中机器的存储访问时，应另行停止或重建相关资源。

## 常见问题 {#troubleshooting}

### 保存按钮不可用，或找不到目标用户

先确认已填写有效相对路径并完成 **读取此目录授权**。若用户或项目列表加载失败，恢复连接后再次读取；新增的每一行都必须选择对象，同一对象不能重复添加。

### 保存时报路径重叠、Fileset 变化或无法核验

点击页面顶部的「刷新」，重新核对 Fileset、完整目录和已有挂载盘登记。同一 Fileset 的共享授权可以重叠，但不同 Fileset 的冲突登记、平台保留空间、数据集占用或授权对象状态变化仍会阻止保存。提示无法核验 Fileset 时，先恢复资源区连接再重试。

### 用户看不到刚授权的目录

核对用户登录名、资源区5、直接个人授权是否保存、挂载盘是否启用。仅有项目授权不会出现在该选择器中；用户的直接授权与项目绑定分别登记，所以已绑定给项目的 Fileset 也可以出现在个人授权目录中。关闭并重新打开创建窗口，重新加载可选目录。

### 已保存授权，但创建时报 AccessDenied {#access-denied}

请平台管理员在资源区5（火山）机器学习平台控制台的 **全局配置 → vePFS → 挂载权限** 中核对**同一完整子目录**、**Zenith 调用身份**及**目标计算队列**的读写权限。保存 Zenith 授权不等于完成云端授权。

本例中，Zenith 输入框填写 `users/alice`；核对云端目录范围时，Fileset 根目录是 `/research`，子目录是 `/users/alice`，合起来才是 `/research/users/alice`。

::: details 通过云端接口配置时的路径对应关系
使用真实 Fileset ID，并分别填写 `FilesetDir=/research`、`SubDir=/users/alice`。不要把完整个人目录 `/research/users/alice` 填成 Fileset 根目录。

云端授权接口可能覆盖已有权限。修改时应保留目录原有的用户、用户组、队列及其读写范围，不能用整盘或整个 Fileset 授权来绕过子目录错误。
:::

### 授权后目录为空，或无法写入

先确认子目录本来就存在，再检查实际挂载及访问模式。Zenith 不会创建该目录，也不会把其他位置的数据复制进来。只读授权不能写入；即使选择“读写”，云端权限仍需允许写入。
